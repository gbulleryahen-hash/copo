COPO

COPO dessine vos pièces en vectoriel, calcule les parcours d'outils (profil, poche, V-carving, perçage) et écrit le G-code pour votre machine. Tout se passe dans le navigateur, sans installation et sans compte.

Votre premier usinage en six étapes

  1. Réglez le projetOnglet Projet : dimensions et matière du brut, point d'origine X0 Y0, zéro Z (dessus du brut ou table), unités et machine.
  2. Dessinez ou importezTracez avec les icônes de l'onglet Dessin, importez un SVG, un DXF, un PDF, un AI ou une image (icône Importer du groupe Créer, ou menu Fichier) ou écrivez un texte.
  3. Vérifiez vos outilsChoisissez le matériau dans l'onglet Projet, puis vérifiez dans la Bibliothèque d'outils (onglet Parcours) la vitesse, l'avance, la profondeur de passe et le pas latéral de chaque fraise.
  4. Créez les parcoursSélectionnez les vecteurs dans la vue 2D, ouvrez l'onglet Parcours, choisissez Profil, Poche, V-carve ou Perçage, réglez puis cliquez sur Calculer.
  5. Contrôlez en 3DLe bouton Simulation de l’usinage (onglet Parcours) ou Usinage › Aperçu 3D de l’usinage montre le brut usiné. Rejouez l'usinage pour repérer une erreur de profondeur ou d'outil.
  6. Enregistrez le G-codeOnglet G-code : choisissez le post-processeur, puis Enregistrer le G-code. Faites toujours un passage à vide avant d'usiner.

L'interface

La fenêtre se lit de gauche à droite, dans l'ordre du travail.

Premier lancement : un écran d'accueil propose une visite rapide (six bulles sur les zones principales), le projet d'exemple ou un projet vide. Ensuite, à la première ouverture de chaque onglet, une ou plusieurs astuces montrent l'essentiel. Passer la visite coupe aussi les astuces. Menu Aide › Visite rapide pour la revoir, Aide › Réafficher les astuces pour les remettre ; la case « Ne plus afficher au démarrage » masque l'écran d'accueil.

  • Bouton Enregistrer (disquette, à gauche de 2D/3D) : la première fois, il demande où enregistrer le projet ; ensuite il réécrit simplement le même fichier (comme Ctrl+S). Un point bleu signale des modifications non enregistrées.
  • Barre de menus : Fichier, Édition, Dessin, Usinage, Extensions et Aide. Le menu Dessin range ses commandes en cinq catégories encadrées : Groupes, Combiner, Vecteurs, Coins et Disposer. Le menu Extensions regroupe les modules qui créent d’un coup dessins et parcours : touche de guitare, incrustation en V, incrustation en poche, boîte à entures et graduations rotatives. Le menu Aide ouvre ce mode d'emploi, permet de signaler un bug et affiche la licence. Les boutons FR / EN, tout à droite de la barre, changent la langue de l'interface ; le bouton qui les suit passe COPO en plein écran (Échap pour en sortir).
  • Onglet Dessin : en haut, une grille d'icônes regroupe toutes les fonctions de dessin, en deux colonnes : à gauche Sélection et Bibliothèque, Créer, Disposer ; à droite Mesurer, Modifier, Combiner ; avec une infobulle et une lettre de raccourci pour chacune. Juste en dessous s'affiche ce dont vous avez besoin : les réglages de l'outil choisi (avec une aide et un petit schéma), le formulaire de la fonction cliquée (Aligner, Copie en réseau, Imbrication, Images…), ou le bloc Sélection quand un vecteur est sélectionné. Les icônes grisées demandent d'abord une sélection. Les calques restent en bas. Échap referme la fonction ouverte.
  • Plan de travail : le brut en beige, les règles en millimètres, la grille et l'origine (flèches X et Y).
  • Panneau de gauche en cinq onglets : Projet, Dessin, Relief, Parcours et G-code. Ils sont numérotés de 1 à 5 dans l’ordre habituel du travail. Dans les onglets Projet et Parcours et dans la bibliothèque d'outils, de petits schémas montrent ce que fait chaque réglage (profondeur, surépaisseur, sens de coupe, entrée de l'outil, ponts, forme de la fraise, zéro Z…) et se mettent à jour avec vos choix.
  • Barre de la vue 2D, flottante en bas à gauche de la vue 2D (les coordonnées du curseur par rapport à l'origine s’affichent en haut à gauche de la vue 2D, sur fond transparent, comme les informations de la vue 3D) : deux groupes d’icônes à allumer ou éteindre (leur nom s’affiche au survol). Accroche (aimant) : grille et son pas, vecteurs, repères, et le bouton de réglages qui ouvre les Règles d'accroche, juste au-dessus. Afficher (œil) : grille, parcours, matière enlevée, traits superposés. Un bouton allumé est entouré de bleu. En bas à droite, le bouton Tout voir montre le brut et tout le dessin ; la vue 3D a les mêmes barres, au même endroit.
  • Infobulles : arrêtez la souris un quart de seconde sur un bouton ou un réglage pour voir ce qu’il fait. L’infobulle disparaît dès que la souris quitte l’élément, et s’affiche aussitôt sur le bouton voisin quand vous explorez. Les flèches ▲ ▼ de la liste des parcours changent leur ordre d’usinage. Dans la liste des parcours, seul le nom s’affiche : l’opération, l’outil, la durée et les éventuels avertissements (pastille !) apparaissent au survol.
  • Calculs dans les champs : dans tout champ numérique, tapez une opération avec + - * (ou x) / et des parenthèses, par exemple 595-140, 73,694/2 ou (10+5)*3 : le résultat remplace le calcul à Entrée ou en quittant le champ.
  • Noms des parcours : un nouveau parcours est nommé calque_fonction_fraise, par exemple femelle_degagement_6mm, femelle_vcarve_90deg ou F2_fond_poche_6mm sur la face 2. Tant que vous ne l’avez pas changé, le nom suit les réglages (autre fraise, autre fonction). Pour renommer un parcours, double-cliquez sur son nom dans la liste (ou F2) : rien n’est recalculé. Dans le formulaire, si seul le nom change, le parcours n’est pas recalculé non plus.
  • Trois niveaux d’aide (1.283) : sous chaque réglage, une ligne courte dit quoi faire. L’icône ⓘ ouvre une bulle avec le détail (pourquoi, quand, raccourcis) : survolez-la, ou touchez-la sur une tablette ; son lien « En savoir plus » ouvre la section correspondante de ce mode d’emploi. Les mots techniques (rampe, ponts, pas latéral, débourrage, surépaisseur…) affichent leur définition quand vous les survolez, sans icône ni soulignage ; sur tablette, touchez le mot. Les avertissements disent la conséquence et la solution, par exemple « Risque de casser la fraise : réduisez la profondeur de passe ».

Un vecteur se sélectionne en cliquant sur son trait (pas à l’intérieur) : les formes empilées restent ainsi accessibles. Une forme déjà sélectionnée peut se déplacer en la glissant depuis l’intérieur.

Clic droit (outil Sélection) : sur un vecteur, dans la vue 2D comme dans la vue 3D, il le sélectionne et ouvre un menu à côté du pointeur. Sur un vecteur : Usiner (Profil, Poche, V-carve, Perçage), Dupliquer, Grouper, Souder, Contour décalé…, Miroir…, Rotation…, Centrer sur le brut, Créer un relief (Dôme, Extrusion), Mettre sur le calque, Copier sur le calque et Supprimer. Sur une image : vectoriser, transformer en relief, ajuster, centrer, ordre d’empilement, verrouiller, supprimer. Sur un relief : parcours d’ébauche, de finition ou de profil, contour, dupliquer, ajuster, centrer, masquer, supprimer, et en 3D déplacer, tourner, redimensionner, poser au fond ou aligner sur le dessus. Dans le vide de la vue 2D, le clic droit ferme l’outil ou les réglages en cours et désélectionne, sans menu ; dans le vide de la vue 3D : tout voir, vue de dessus, vue de face. Avec la plume ou un autre outil de tracé, le clic droit termine toujours le tracé ; en 3D, le clic droit glissé déplace toujours la vue. Dupliquer (Ctrl+D) crée la copie sur place, sélectionnée : faites-la glisser ou déplacez-la aux flèches. Les traits superposés (doublons, copies non déplacées, bords communs, imports DXF en double) sont surlignés en rose, pour les repérer d’un coup d’œil : la fraise passerait deux fois sur ces portions. Le bouton Traits superposés du groupe Afficher (ou Paramètres › Affichage) active ou désactive ce surlignage.

Dessiner

Le panneau Dessin, comme dans Aspire : quand vous choisissez un outil ou une fonction de la grille, ses réglages remplacent les icônes. La croix bleue en haut à droite, ou un clic droit dans le vide du dessin, les ferme et ramène la grille. Quand vous cliquez un vecteur, la grille reste et ses réglages (Sélection, image…) s'affichent dessous ; les textes d'aide s'ouvrent avec l'icône ⓘ.

Formes et tracés

  • Rectangle R, avec coins carrés, en rayon externe, en rayon interne (arcs creusés) ou chanfreinés. Ellipse E (Maj : cercle) et Cercle par le centre C.
  • Valeurs chiffrées (cercle, ellipse, rectangle, polygone et étoile, arc) : le panneau de l’outil affiche des champs comme dans Aspire. Cercle : centre X/Y, rayon ou diamètre. Ellipse et rectangle : point de référence (grille de 9 points), X/Y, largeur et hauteur. Polygone et étoile : centre, rayon, angle. Arc : point de départ, point d’arrivée, rayon et hauteur (flèche), liés entre eux. Tracez à la souris : la forme reste sélectionnée et les valeurs la modifient directement (coins et nombre de côtés compris) ; Valider la termine, vous pouvez tracer la suivante. Sans forme en cours, saisissez les valeurs puis Créer. Pour reprendre plus tard une forme tracée ainsi (même déplacée ou redimensionnée), sélectionnez-la et cliquez sur l’icône crayon Modifier les cotes de la section Sélection.
  • Polygone et étoile O : nombre de côtés ou de branches, rayon intérieur. Cliquez au centre puis glissez : le 2ᵉ point s’accroche à l’horizontale et à la verticale du centre (Ctrl : par pas de 15°).
  • Plume P (premier outil de la rangée Créer) : clic pour un point anguleux, cliquer-glisser pour un point courbe, clic sur le premier point pour fermer, double-clic pour terminer. Près de l’horizontale ou de la verticale du point précédent, le trait s’y aligne tout seul (repère « Horizontale » / « Verticale » et pointillés) ; avec Ctrl, l’angle avance par pas de 15° (0°, 45°, 90°…). Prolonger une ligne : commencez la Plume sur l’extrémité d’une ligne ouverte (repère « Extrémité ») ; le tracé continue cette ligne au lieu d’en créer une nouvelle, et la courbe vers le point suivant part exactement dans son axe (tangente). Glissez depuis ce premier point, dans l’axe, pour régler la tension de la courbe. La barre d’espace termine la ligne en cours et en commence une nouvelle ; le clic droit termine la ligne et quitte la plume. Le bloc Point suivant du panneau sert à créer les points au clavier : tapez X et Y (position absolue), ou un angle et une longueur L, ou dx et dy depuis le dernier point. Les six champs restent liés (en tapant l’angle et la longueur, X, Y, dx et dy se calculent) et un aperçu en pointillés montre le point. Entrée ou Ajouter le pose, Annuler retire le dernier point, Fermer et Terminer finissent le tracé.
  • Arc A : par 3 points (départ, arrivée, puis le bombé) ou, en mode Centre, départ, arrivée, clic au centre, au départ puis à l’arrivée : l’arc part du côté vers lequel vous tournez la souris autour du centre.
  • Nœuds N : déplacez nœuds et poignées, double-cliquez sur un segment pour ajouter un nœud, Alt en tirant une poignée pour la casser, Maj pour la garder horizontale ou verticale par rapport à son nœud. Un clic sur une poignée la sélectionne (rond orange) : ses coordonnées X/Y s’affichent dans le panneau, en absolu ou en relatif, et se modifient comme celles d’un nœud. Les champs L (longueur de la poignée, sa distance au nœud) et Angle (0° vers la droite, 90° vers le haut) se règlent aussi : changer L garde la direction, changer l’angle garde la longueur. En les glissant, nœuds et poignées s’accrochent aux lignes et au prolongement des segments droits (repère « Prolongement » en pointillés) : posez la poignée d’une courbe sur le prolongement de la ligne qui la précède, la courbe lui est tangente. Quatre types de nœuds : Lisse (rond, poignées alignées), Symétrique (rond pointé, poignées alignées et de même longueur : tirer l’une déplace l’autre en miroir), Brisé (losange, deux poignées indépendantes pour un angle entre deux courbes) et Coin vif (carré, sans poignées). Plusieurs nœuds : Maj+clic pour en ajouter ou en retirer, cadre tracé dans le vide pour les prendre tous d'un coup (Maj pour compléter), Ctrl+A pour tous. Les nœuds sélectionnés se déplacent ensemble à la souris ou aux flèches (1 mm, Maj 10 mm, Ctrl pas fin selon le zoom, Alt ÷ 10). Les champs X et Y donnent la position du nœud en Absolu ; en Relatif, tapez un déplacement puis Entrée : il s’applique à tous les nœuds sélectionnés. Les boutons sont rangés par usage : types de nœuds (Brisé, Coin vif, Lisse, Symétrique), segments (courbe, droit), ajouter, supprimer, couper, puis Scinder et Ouvrir / fermer ; Lisse, Coin vif et Suppr s'appliquent à tous. Un segment sélectionné (cliquez dessus, il passe en rouge) se supprime avec Supprimer ou Suppr : un contour fermé devient une ligne ouverte, une ligne ouverte est coupée en deux. Pour passer à une autre forme, cliquez sur son contour. Scinder (aussi dans la rangée Modifier) coupe le profil à chaque nœud : chaque segment devient un vecteur séparé.

Modifier

  • Chanfrein K et Congé F sur un coin, ou sur tous les coins vifs via le bloc Coins. Le coin peut aussi être formé par deux vecteurs séparés qui se touchent (une ligne et un arc, par exemple) : COPO les joint en un seul vecteur puis fait le congé ou le chanfrein.
  • Copier, couper, coller : Ctrl+C, Ctrl+X, Ctrl+V (aussi dans le menu Édition). Chaque collage est décalé de 10 mm et reste sélectionné ; les groupes et les calques sont conservés. Le presse-papiers sert aussi d'un projet à l'autre. Avec un relief sélectionné, Ctrl+C puis Ctrl+V en colle une copie.
  • Ajuster X supprime la portion de vecteur entre deux intersections ; Couper U coupe un vecteur à l'endroit cliqué.
  • Étendre les vecteurs (groupe Modifier) : cliquez le trait ouvert à prolonger, puis approchez la souris d’une de ses extrémités. Son prolongement s’affiche en pointillés, dans la direction du tracé, avec un rond à chaque croisement avec un autre vecteur. Cliquez un croisement : le trait est prolongé jusque-là. Vous pouvez continuer vers le croisement suivant ; Échap permet de choisir un autre trait.
  • Souder, Soustraire, Intersection pour les opérations booléennes ; Joindre et Fermer pour les vecteurs ouverts, les écarts étant comblés par une ligne droite ou par une courbe lisse qui prolonge les deux tracés ; Contour décalé : sur un vecteur fermé à l'extérieur, à l'intérieur ou des deux côtés ; sur un vecteur ouvert à droite ou à gauche du tracé, ou tout autour (« Les deux » crée un contour fermé). Une distance négative passe de l’autre côté (−1 en Extérieur = 1 mm à l’intérieur). Angles nets ou arrondis, et option pour supprimer l'original
  • Lisser (adapter des courbes) (Modifier) : remplace les vecteurs faits de nombreux petits segments (vectorisation, DXF, import) par des arcs, des courbes de Bézier ou des lignes droites qui restent à moins de la tolérance du tracé d'origine. « Garder les coins saillants » conserve en angle vif les coins dont le changement de direction dépasse l'angle max (60° par défaut). Un aperçu en pointillés orange et le nombre de nœuds avant/après s'affichent avant d'appliquer ; décochez « Remplacer » pour garder les originaux. Arcs ou Bézier ? Dans COPO, toutes les courbes (cercles, arcs, ellipses, lettres) sont enregistrées en courbes de Bézier, comme dans un fichier SVG. Le mode Arcs repère les portions qui suivent un vrai cercle (centre et rayon constants) et les trace avec des Bézier calées sur cet arc, au plus une par quart de cercle : l'écart avec l'arc parfait est d'environ 0,03 % du rayon (moins d'un centième de millimètre pour 30 mm de rayon). Choisissez-le pour les formes mécaniques (gabarits, congés, trous) : les rayons sont vraiment constants et donnent des G2/G3 propres. Le mode Courbes de Bézier donne des courbes libres, souvent avec moins de nœuds sur les formes organiques (dessin vectorisé, volute), mais un « rond » n'y est pas forcément un cercle exact.
  • Aligner et répartir (vecteurs ou reliefs ; pour les reliefs, Maj + clic dans la vue 2D en choisit plusieurs, et les mêmes boutons sont dans l'onglet Relief) : choisissez la référence dans « Aligner sur ». La sélection : un seul vecteur s'aligne sur le brut, plusieurs s'alignent entre eux. Le premier vecteur sélectionné : il ne bouge pas et les autres s'alignent sur lui ; Répartir les place à sa suite, dans l'ordre où vous les avez sélectionnés, avec l'espacement indiqué. Le brut : alignement sur les bords du brut, répartition sur toute sa largeur ou sa hauteur.
  • Bloc Sélection : disposé comme dans les logiciels de dessin vectoriel : à gauche le point de référence (neuf points), puis X et Y, puis L (largeur) et H (hauteur), et le cadenas qui garde les proportions (bleu : activé). En dessous, l’angle de la sélection : tapez une valeur, la sélection prend cet angle en tournant autour du pivot ; puis la case Cadre rotatif et les boutons modifier, dupliquer, supprimer.
  • Rotation (Disposer) : un pivot orange apparaît au centre de la sélection ; faites-le glisser dans la vue 2D (il s'accroche aux vecteurs, aux repères et à la grille), ou choisissez l'un des neuf points, ou tapez ses coordonnées. Rotation relative (la sélection tourne de l'angle indiqué, positif dans le sens inverse des aiguilles d'une montre) ou absolue (la sélection prend l'angle indiqué, COPO retient les rotations déjà faites). Boutons ↺ 90° et ↻ 90° pour les quarts de tour.
  • Poignées : cliquez une seconde fois sur un vecteur déjà sélectionné. Les carrés redimensionnent (coins proportionnels si le cadenas « Garder les proportions » est activé, Maj pour l'inverse, Ctrl pour avancer au millimètre ; milieux sur un seul axe), les ronds font tourner autour du pivot (Ctrl : angle arrondi à 15° près, 0, 15, 30… ; Ctrl + Maj : au degré près), et le pivot se déplace. Un nouveau clic les masque. La case Cadre rotatif (bloc Sélection, décochée par défaut, sous « Garder les proportions ») fait suivre au cadre l’angle d’une forme tournée : on l’étire alors dans son propre sens, comme dans Aspire (pour une forme seule, ou des formes tournées du même angle ; une ligne droite prend son orientation : sa largeur est alors sa longueur). La largeur et la hauteur du bloc Sélection sont alors celles de la forme dans son propre sens, et les modifier l’étire dans ce sens.
  • Déplacer au clavier : les flèches déplacent la sélection de 1 mm (Maj : 10 mm). Avec Ctrl, le pas s’adapte au zoom : environ un pixel de l’écran, arrondi à 1, 2 ou 5 (0,05 mm de près, 1 mm de loin), pour caler un vecteur au plus juste ; Ctrl+Maj : dix fois plus. Le pas utilisé s’affiche. Même chose pour les nœuds et les images.
  • Clic droit et double-clic : un seul clic droit dans la vue 2D termine la ligne en cours (polyligne), annule un tracé commencé, revient à l'outil de sélection et désélectionne ; en sélection, il masque les poignées puis désélectionne. Le double-clic sur un vecteur, depuis la sélection ou un outil de forme (rectangle, ellipse, cercle, polygone, arc, cote, mesure), le sélectionne avec ses poignées ; un nouveau double-clic ouvre l'édition de ses nœuds (Échap ou clic droit pour en sortir).
  • Miroir (groupe Disposer) : retourne la sélection par rapport au bord du dessus, de gauche, de droite ou du dessous de son cadre, horizontalement ou verticalement (autour de son centre, ou du centre du brut si la case est cochée), ou par rapport à une ligne droite sélectionnée avec les formes (Retourner sur la ligne). Des petites icônes (la lettre P et son reflet) montrent l’effet de chaque bouton. La case Créer une copie en miroir garde l’original en place.
  • Contour (dernière icône du groupe Créer) : avec une image sélectionnée, ouvre sa vectorisation ; avec un relief sélectionné, crée le vecteur qui suit son pourtour.
  • Copie en réseau en grille, circulaire ou le long d’une courbe (aussi l’icône Répéter le long d’une courbe de Disposer) : sélectionnez les vecteurs à répéter puis, en dernier, la courbe guide (Maj+clic) ; indiquez le nombre de copies, réparties sur toute la courbe ou avec un espacement, un décalage au départ, et cochez Orienter selon la courbe pour qu’elles tournent avec elle. Miroirs, rotation, ordre de superposition.
  • Position et taille exactes : bloc Sélection, avec un point de référence choisi parmi neuf (coins, milieux, centre).

Accrochage, repères et cotes

Édition › Paramètres › Accroche regroupe les règles d'accroche : grille et son pas, repères, coins, milieux et centre du brut, rayon d'accroche (petit à grand), et accroche aux vecteurs avec ses six types de points (extrémités et nœuds, milieux, intersections, centres, tangentes, et sur le tracé : n’importe quel point d’une ligne ou d’une courbe, le plus proche du curseur). Les points précis (extrémité, milieu…) restent prioritaires sur « sur le tracé ». Centre d’un cercle ou d’un arc : passez la souris près de son contour, une petite croix orange montre le centre ; allez dessus pour vous y accrocher (y compris pour les cercles faits de segments droits, importés ou vectorisés). L’origine (X0 Y0) est toujours un point d’accroche. Quand vous déplacez un vecteur en le saisissant par un de ses points (nœud, coin, milieu, centre), c’est ce point qui s’accroche : glissez le coin d’un rectangle sur l’origine, il s’y pose exactement. Ces réglages sont mémorisés. Glissez depuis une règle pour créer un repère : les points dessinés s'y accrochent, et en déplaçant une sélection, ses bords et son centre s'alignent sur les repères (et sur le brut si cette case est cochée). Un double-clic sur un repère ouvre le bloc Repères (groupe Mesurer) sur sa position, à changer au clavier ; le cadenas de chaque ligne bloque le repère, qui ne bouge plus à la souris. Un symbole orange au curseur indique l'accroche trouvée. L’icône de grille, sous la vue 2D, montre ou cache la grille. L'outil Mesurer M donne une distance et l'outil Cote D pose une cote qui reste dans la vue 2D. Une extrémité accrochée à un nœud, au milieu d'un segment ou au centre d'un arc ou d'un cercle (point plein au bout de la ligne d'attache) reste liée au vecteur : si vous le déplacez, le redimensionnez ou modifiez ses nœuds, la cote suit et sa valeur se met à jour. Une extrémité posée ailleurs (grille, intersection, point libre) reste fixe.

Calques, images et fichiers

  • Calques : couleur des traits, visibilité, verrou et face usinée (F1 dessus, F2 dessous). Supprimer un calque qui contient des vecteurs demande s’il faut les déplacer sur un autre calque ou les supprimer aussi. Sous la liste, Sélection → calque actif déplace la sélection sur le calque actif et Copie → calque actif l’y copie (les copies sont sélectionnées, les originaux restent en place) ; le clic droit propose aussi Mettre sur le calque et Copier sur le calque.
  • Images de référence (icône Importer › Image, Fichier › Insérer une image… ou glisser-déposer) : déplacez, redimensionnez et pivotez avec les poignées pour dessiner par-dessus. Elles ne sont jamais usinées.
  • Bibliothèque de dessins et d’images (icône Bibliothèque du panneau Dessin, ou Fichier › Bibliothèque de dessins et d’images…) : à gauche les dossiers, à droite les aperçus. Ajouter au dessin (ou un double-clic) place le dessin (SVG, DXF, PDF, AI) ou l’image (PNG, JPG…) choisi. Nouveau dossier, Ajouter des fichiers… et Ajouter un dossier… (tout un dossier de l’ordinateur, avec ses sous-dossiers) la remplissent ; Importer le dessin en cours (aussi Fichier › Ajouter le dessin en cours à la bibliothèque…) l’enregistre en SVG, ou seulement la sélection. Exporter ma bibliothèque… et Importer ma bibliothèque… la sauvegardent ou la transfèrent sur un autre ordinateur (fichier .copolib). L’engrenage en haut ouvre Paramètres › Bibliothèque : la bibliothèque peut rester dans le navigateur, ou être un dossier de l’ordinateur (Chrome et Edge) fait de vrais fichiers, que vous rangez aussi avec l’explorateur ; taille des aperçus et double-clic s’y règlent aussi.
  • Bibliothèque COPO : sous « Ma bibliothèque », le dossier Bibliothèque COPO contient des dessins 2D (contours fermés, en mm) et des reliefs en niveaux de gris fournis avec COPO, rangés par catégorie (Dessins 2D : coins, formes, Noël, panneaux et boucliers ; Reliefs : animaux, décoratif, objets, plantes, rubans, textures…). Ils sont libres, même pour vendre vos pièces, et arrivent du site : il faut être en ligne la première fois, ensuite ils restent disponibles hors ligne. Ce dossier est en lecture seule : Ajouter au dessin place l’élément, Copier dans ma bibliothèque le recopie dans vos dossiers pour le renommer ou le modifier. Une image en niveaux de gris se place sur le dessin ; on en fait un relief dans l’onglet Relief. La liste complète, avec les sources et licences, est aussi sur la page Bibliothèque du site.
  • Régler une image (panneau Dessin, image sélectionnée) : centre, angle, largeur, hauteur et opacité tiennent sur deux lignes ; la rangée d’icônes en dessous sert à ajuster au brut, centrer, remettre l’angle à 0°, changer l’ordre d’empilement, verrouiller et retirer l’image (le nom de chaque bouton s’affiche au survol). Le détail des aides s’affiche dans la bulle de l’icône ⓘ.
  • Vectoriser une image (section repliable Vectoriser sous les réglages de l’image ; repliée, elle rappelle le seuil et le lissage) : COPO trace les contours de l'image. Réglez le seuil (ce qui est plus sombre devient la forme ; « Seuil automatique » le calcule pour vous) et le lissage (contours plus doux, petits détails retirés), cochez Inverser pour contourner les zones claires. L'aperçu se met à jour en direct ; Créer les contours ajoute des formes fermées et groupées à l'emplacement de l'image, prêtes pour une poche, un profil ou un V-carving. Une image nette et bien contrastée (logo, dessin au trait, silhouette) donne le meilleur résultat.
  • Importer : l'icône Importer du groupe Créer ouvre un panneau à deux choix, Vectoriel (SVG, DXF, PDF, AI) et Image (image de référence à décalquer ou à vectoriser).
  • SVG : import en millimètres avec courbes conservées ; export du dessin entier ou de la sélection.
  • PDF et AI : les vecteurs de la première page sont importés à l'échelle (en mm), courbes conservées ; les zones de détourage, les images et les textes non vectorisés sont ignorés. Les fichiers Illustrator doivent avoir été enregistrés avec « Créer un fichier compatible PDF » (réglage par défaut) ; un très ancien AI (PostScript) est refusé avec un message. Vectorisez les textes avant l'export (Texte › Vectoriser).
  • DXF (texte/ASCII, toutes versions) : lignes, polylignes avec arcs, cercles, arcs, ellipses, splines et blocs. L'unité du fichier est respectée (mm, cm, pouces…) ; un fichier sans unité est lu en millimètres. Les segments qui se touchent sont reliés en contours, fermés quand c'est possible, et chaque calque DXF devient un calque COPO. Les textes, cotes, hachures et objets 3D sont ignorés (le message indique lesquels).

Coins pour tenons et mortaises : dogbone et T-bone

Une fraise ronde laisse un arrondi de son rayon dans les coins : un tenon à angles vifs n'entre pas dans la mortaise. Le dégagement se dessine sur la forme, coin par coin, pour ne le mettre que là où il faut. Prenez l'outil Dégagement B (groupe Modifier), choisissez Dogbone (la fraise va en diagonale toucher le coin vif) ou T-bone (le dégagement prolonge le côté le plus long, moins visible) et le diamètre de la fraise, puis cliquez près des coins à dégager. Les mêmes réglages se trouvent dans le bloc Coins du panneau Dessin. Les coins se choisissent un par un, comme pour les chanfreins et les congés. Le dégagement ne se fait qu'entre deux segments droits ; son diamètre a 0,1 mm de plus que la fraise pour qu'elle passe sans forcer. Usinez ensuite la forme normalement (poche, profil intérieur ou extérieur) avec cette fraise.

Onglet Projet

L'onglet Projet, le premier du panneau de gauche, s'ouvre tout seul quand vous créez un nouveau projet. Il contient :

  • Type de projet : Simple face, Double face (le bloc Double face apparaît) ou Rotatif (4ᵉ axe). Les réglages en dessous changent selon le choix. Si la machine choisie n’a pas d’axe rotatif déclaré, un avertissement s’affiche sous le choix Rotatif, sans rien bloquer.
  • Rotatif : la pièce est un cylindre qui tourne entre un mandrin et une contre-pointe. Taille du travail : longueur (L) et diamètre (D). On dessine sur la surface du cylindre déroulée, comme une étiquette mise à plat : la feuille fait L sur π × D (le tour du cylindre, calculé tout seul). Le milieu de la feuille est le dessus du cylindre ; des lignes pointillées marquent 90°, 180° et 270° et les bords de la feuille sont la jonction (0° = 360°) : un motif qui la traverse doit se raccorder. Zéro Z : surface ou axe du cylindre. Orientation : axe de rotation le long de X (Y s’enroule) ou de Y (X s’enroule). La vue 3D et la simulation montrent la pièce enroulée sur le cylindre (case à décocher pour revenir à plat, par exemple pour placer un relief avec les poignées). Au G-code, la coordonnée enroulée sort en angle A (ou B, selon la machine ; en degrés), avec n’importe quel post-processeur, et les arcs sont remplacés par de petits segments ; un post-processeur « Wrap » ou « Rotary » (.pp) peut aussi être utilisé. Les profondeurs se mesurent vers le centre : plus on creuse, plus le motif se resserre.
  • Brut : largeur X, hauteur Y, épaisseur et matière (reprise par la fiche de gamme) ;
  • Origine : le point X0 Y0 sur la grille de neuf points, un décalage X/Y pour la placer hors du brut, et le zéro Z sur le dessus du brut ou sur la table ;
  • Double face : l'axe de retournement et les faces affichées ;
  • Unités : millimètres ou pouces, unité d'avance ;
  • Machine (en haut de l’onglet) : le nom de la machine utilisée et son post-processeur ; Changer… ouvre la bibliothèque de machines. À gauche, la liste des machines (celle qui est cochée sert au G-code ; un clic en choisit une autre), avec + Nouvelle machine, Dupliquer et Supprimer (deux clics pour confirmer). À droite, ses réglages, enregistrés automatiquement : nom, course X/Y/Z (facultative : l’onglet Projet signale un brut plus grand), plage de vitesse de broche (les vitesses des outils y sont ramenées dans le G-code), axe rotatif installé et sa lettre (A ou B), notes. Avec le post-processeur « GRBL manuel » ou personnalisé, la case Remonter à un Z machine (G53) au changement d’outil est désactivée par défaut : une valeur de Z machine mal réglée peut envoyer la broche en butée ; désactivée, la broche remonte au Z de sécurité et les lignes G53 sont retirées, et : post-processeur, vitesse des rapides, avance de travail maximale (2000 mm/min par défaut : les avances des outils sont plafonnées à cette valeur), Z de sécurité et de dégagement, arcs G2/G3 et commentaires. La case Cycles de perçage G81/G82/G83 écrit les perçages en cycles : G81 simple, G82 avec temporisation au fond, G83 avec débourrage, remontée G98 au Z de dégagement. G83 ne prévoit pas de temporisation : un perçage avec débourrage et temporisation reste écrit en G0/G1. Elle est cochée d’office pour grblHAL, LinuxCNC, Mach3/4, UCCNC et MASSO, et décochée pour GRBL, Carbide Motion, Onefinity et le post-processeur personnalisé (les perçages y sont écrits en G0/G1) ; on peut toujours la changer. Si le contrôleur ne connaît pas ces cycles, il s’arrête simplement sur une erreur.

Le point d'origine doit correspondre à l'endroit où vous faites X0 Y0 sur la machine. Le brut, l'origine et la matière sont enregistrés avec le projet. Les unités et la machine restent en mémoire dans le navigateur.

Exemple : avec l'origine au coin bas gauche, un carré dont le coin est à X0 Y0 dans la vue 2D sera usiné à partir du coin bas gauche de votre panneau. La ligne sous la grille indique où tombe X0 Y0 du G-code.

Bibliothèque de machines

Dans l’onglet Projet, Machine › Changer… ouvre la bibliothèque. Chaque machine garde son post-processeur, ses vitesses, ses hauteurs de sécurité, sa course X/Y/Z, sa plage de broche et son axe rotatif (lettre A ou B). La machine par défaut utilise le post-processeur GRBL (pause M0 au changement d’outil), et la remontée à un Z machine (G53) au changement d’outil est désactivée par défaut. Le changement d’outil se règle aussi dans la machine : Selon le post-processeur (par défaut), Aucune commande (l’outil n’apparaît qu’en commentaire), Commande de pause (M0 ou une autre commande, à chaque changement) ou Commande de changement (commande de début, n° d’outil, commande de fin : « T6 M6 », « M6 T6 »…), avec un exemple sous les champs. Le numéro d’outil (T…) est celui de la fraise dans la bibliothèque d’outils ; si deux outils du programme ont le même numéro, un avertissement s’affiche sous le G-code. Ce réglage ne s’applique pas aux post-processeurs .pp, qui définissent eux-mêmes le changement d’outil. Exporter… enregistre toutes les machines dans un fichier machines-copo.json (autre ordinateur, sauvegarde) ; Importer… ajoute les machines d’un tel fichier sans rien remplacer.

Paramètres

Édition › Paramètres… (Ctrl+,) ouvre une fenêtre à rubriques : les titres à gauche, le contenu qui défile à droite (cliquez un titre pour y aller ; le titre de la partie affichée s’allume). Tout est enregistré dans le navigateur.

  • Général : langue de l’interface, écran d’accueil au démarrage, astuces des onglets (et Réafficher toutes les astuces), visite rapide, recalcul des parcours après une modification du dessin (Automatique ou Manuel, voir Parcours d’outils).
  • Accroche : grille et son pas, repères, brut, rayon d’accroche et accroche aux vecteurs (voir Dessiner). Le bouton d’accroche de la barre de la vue 2D ouvre directement cette rubrique.
  • Affichage : Thème Sombre (par défaut) ou Clair « Établi clean » (fond crème, outils sans cadre, accent bleu acier), appliqué tout de suite et retenu par le navigateur ; les captures de ce mode d’emploi restent en thème sombre. Résolution du relief, comme dans Aspire : Standard (le plus rapide), Haute (environ 3 × plus lent, recommandée) ou Très haute (environ 7 × plus lent) ; quelle que soit la résolution, un relief que l’on déplace suit la souris immédiatement, affiché un peu moins fin, et l’affichage fin revient au lâcher ; les parois verticales (pièce STL, bord d’un relief) sont lissées, sans stries ni bord en escalier ; le parcours d’usinage n’est pas concerné, grille, parcours, nom et temps de chaque parcours dans la simulation (sous le temps de la vue 3D ; ▸ marque le parcours en cours, ✓ ceux qui sont terminés ; décochée par défaut), matière enlevée, traits superposés, extrémités des lignes ouvertes, reliefs dans la vue 2D.
  • Vues 3D : boutons de la souris (par défaut comme Fusion, FreeCAD, Tinkercad : clic droit maintenu = tourner, clic molette maintenu = déplacer ; ou Classique : clic gauche = tourner, clic droit = déplacer ; Maj + clic droit déplace sur un pavé tactile) et centre de rotation : Origine, Centre de la vue ou Sous le pointeur (par défaut).
  • Vues 3D (suite) : zoom à la molette vers le pointeur (par défaut) ou vers le centre de la vue. Couleur du relief : bronze (par défaut), aluminium, bois clair, bois foncé ou plastique, la même dans la vue 3D et dans la simulation.
  • Bibliothèque : emplacement de la bibliothèque de dessins et d’images (dans le navigateur ou dans un dossier de l’ordinateur), taille des aperçus, effet du double-clic.
  • Simulation : résolution par défaut de l’aperçu 3D (Standard, Haute ou Très haute).

Les unités et la machine restent dans l’onglet Projet, à portée de main. L’onglet G-code rappelle le post-processeur choisi ; Changer… ouvre la bibliothèque de machines.

Bibliothèque d'outils

La bibliothèque s'ouvre par la carte Bibliothèque d'outils du bloc Outils de l'onglet Parcours (elle rappelle le matériau du projet), par Usinage › Bibliothèque d'outils…, et par le bouton Outil de la fenêtre d'un parcours. Inspirée de celle d'Aspire, elle est livrée remplie : outils métriques (mm) et impériaux (pouces), rangés en fraises droites, hémisphériques, Fraises en V (dont des fraises de 30° pour la gravure fine et les fraises carving carbure Ø 10 et Ø 32 à queue de 6 mm), Fraises javelot (V à bout plat, carbure, 15° à 90°, plat de 0,1 ou 0,2 mm, 1 ou 2 dents), Fraises V à bout rond et forets, nommées comme dans les catalogues (« Fraise V 90° Ø12 mm », « Javelot 30° × 0,2 mm – Ø3,175 mm (2 dents) », « Fraise V à bout rond R0,25 – L15 – Ø3,175 mm » : rayon, longueur de coupe et Ø de queue, sans angle, comme sur les catalogues ; 29 fraises du catalogue sont fournies, de R0,25 à R2 et de Ø3,175 à Ø8, avec les réglages du tableau du fabricant (diamètre de coupe = 2 R, bas de la plage)), avec leurs réglages pour huit matériaux : bois tendre, bois dur, MDF, acrylique, PVC, PEHD, aluminium et laiton. Les quatre premiers viennent d'une bibliothèque Aspire réglée sur une machine de type WorkBee ; les réglages qui y manquaient sont estimés pour une CNC de loisir d'après les tableaux de CncFraises (« hobby », très prudents) et de Sorotec (petits diamètres) : avance par dent selon le matériau et le diamètre, vitesse de broche tirée de la vitesse de coupe (entre 8 000 et 18 000 tr/min, avance plafonnée à 2 000 mm/min), profondeur de passe k × Ø (de 0,5 à 1 × Ø dans les matériaux tendres, 0,1 à 0,35 × Ø dans l'aluminium et le laiton), réduite parce que la fraise travaille souvent sur toute sa largeur. Le PVC reprend les réglages de l'acrylique. Les valeurs estimées sont signalées par un bandeau orange : faites un essai et corrigez-les. Sous les réglages, un conseil rappelle les règles du matériau (copeaux et non poussière, lubrification de l'aluminium, plastiques qui fondent…) et de la fraise ; un bandeau prévient quand la fraise est déconseillée pour ce matériau (javelot 2 dents ou fraise carving dans l'aluminium).

Vos modifications sont enregistrées dans la bibliothèque : elles servent à tous les parcours et à tous les projets qui utilisent cet outil avec ce matériau (une bulle le rappelle à la première modification). Un bandeau Vous avez modifié ces réglages les signale, avec le bouton Revenir aux valeurs d'origine qui rétablit les réglages livrés avec COPO, ou l'estimation, pour ce matériau. Le commentaire sous l'avance par dent passe en orange quand l'avance par dent sort des repères ou quand la profondeur de passe dépasse k × Ø.

  • Matériau (en haut) : c'est le matériau du projet, aussi réglable dans l'onglet Projet (Matériau des outils). En le changeant, tous les outils du projet reprennent les réglages de ce matériau et les parcours sont recalculés. Le bouton + ajoute un matériau.
  • Arbre (à gauche) : cliquez sur un dossier pour l'ouvrir, double-cliquez pour le renommer ; la recherche filtre par nom ; « utilisé » marque les outils des parcours du projet. En bas : nouvel outil, nouveau dossier, dupliquer, supprimer et revenir à la bibliothèque par défaut (deux clics). Les boutons Importer… et Exporter… sont en haut à droite.
  • Réglages (à droite) : la géométrie (nom, type, diamètre, angle, pointe des fraises de gravure, nombre de dents, numéro T, notes), puis les réglages de coupe pour le matériau choisi. Le nom se met à jour seul tant que vous ne l'avez pas modifié.

Choisir l'outil d'un parcours

Dans la fenêtre d'un parcours, le bouton Outil affiche l'outil choisi ; cliquez dessus pour ouvrir la bibliothèque, sélectionnez l'outil puis Utiliser cet outil (ou double-cliquez). Les outils qui ne conviennent pas au type de parcours sont grisés. Le parcours reprend les réglages de l'outil pour le matériau du projet, et sa profondeur de passe. Modifier un outil dans la bibliothèque met à jour les parcours qui l'utilisent. Un nouveau parcours prend la fraise droite de 6 mm du projet quand elle convient.

Importer une bibliothèque Aspire

Le bouton d'import lit directement les bibliothèques d'Aspire, VCarve et Cut2D (fichier .vtdb, par exemple C:\ProgramData\Vectric\Aspire\V12.0\ToolDatabase\tools.vtdb, ou un export depuis la bibliothèque d'Aspire). Les outils, leurs dossiers et leurs réglages par matériau sont ajoutés dans un dossier « Import Aspire », pouces convertis en millimètres ; si le fichier contient plusieurs machines, COPO demande laquelle reprendre. Les matériaux absents (PVC, PEHD, aluminium, laiton) sont estimés. Les outils de forme et les pointes diamant, que COPO ne sait pas encore usiner, sont ignorés. L'import accepte aussi une bibliothèque COPO exportée en .json.

Relief (modélisation)

L’onglet Relief prépare un usinage sculpté, comme la modélisation d’Aspire : chaque élément de relief est une carte des hauteurs posée dans le brut. L’onglet ouvre la vue 3D à côté du dessin (boutons 2D / 3D) ; les boutons de création indiquent leur mode d’emploi au survol.

  • Niveaux de gris : insérez l’image (PNG, JPG) dans l’onglet Dessin (Importer › Image), placez-la et dimensionnez-la, sélectionnez-la puis cliquez sur Niveaux de gris : l’image est transformée en relief à la même place, à la même taille et au même angle, et elle quitte la vue 2D. Le relief s’affiche ombré dans la vue 2D et se manipule comme un vecteur. Le clair est en haut, le foncé en bas (case Inverser pour l’inverse). Un fond transparent compte comme du noir pour les hauteurs, mais il n’est pas usiné : sans limite sélectionnée, l’usinage reste dans la partie opaque de l’image. Pour une image sur fond noir (un JPG, par exemple), cochez Fond noir → transparent, aucun relief (seuil) : ce qui est plus sombre que le seuil (8 % par défaut) devient transparent et n’est ni en relief ni usiné, et le reste du relief part de zéro au bord, sans marche.
  • Modèle 3D (STL binaire ou texte) : le modèle est vu de dessus et projeté en hauteurs, à sa taille réelle : il n’est jamais réduit, même s’il dépasse le brut. Dans ce cas, un message et le résumé du panneau (en rouge) le signalent : agrandissez le brut dans l’onglet Projet, ou réduisez le modèle vous-même. Si le modèle arrive couché ou à l’envers, Angle X et Angle Y le basculent (180° sur X pour le retourner, ±90° pour le relever), Angle Z le fait tourner à plat (seul l’angle Z existe pour les autres reliefs). Les contre-dépouilles sont usinées telles que vues d’en haut. Aussi depuis Fichier › Importer un STL (relief)….
  • Réglages de chaque élément : position et taille comme pour un vecteur (point de référence parmi neuf, X, Y, largeur, hauteur), épaisseur du relief, haut du brut → haut du relief et bas du brut → bas du relief (modifier l’un recalcule l’autre : leur somme plus l’épaisseur fait l’épaisseur du brut), angle, adoucissement et combinaison avec les éléments précédents : ajouter, soustraire, garder le plus haut ou le plus bas, ou mélanger : là où les reliefs se chevauchent, leurs hauteurs font une moyenne, fondue vers les bords de l’élément, sans s’additionner ni se soustraire. « Garder les proportions » fait suivre l’épaisseur quand on change la taille. Pour supprimer un élément, cliquez la corbeille sur sa ligne dans la liste. Quand un relief est sélectionné, ses réglages prennent la place des boutons de création ; la croix bleue, ou un clic droit dans le vide du dessin, les referme.
  • Limiter par des vecteurs : cliquez sur Limiter par des vecteurs…, puis choisissez dans la vue 2D un ou plusieurs vecteurs fermés et cliquez sur Valider la limite. Le relief n’existe qu’à l’intérieur de ces vecteurs (une forme dans une autre fait un trou) ; en dehors il n’y a pas de relief. La limite suit les vecteurs si vous les modifiez ; Retirer la limite rend tout le cadre au relief.
  • Créer le contour : avec un relief sélectionné, ce bouton crée un vecteur fermé qui suit son pourtour vu de dessus (STL, image, dôme, lissage…), en tenant compte de sa rotation et de sa limite. Il suffit ensuite de lui appliquer un parcours Profil à l’extérieur pour détourer la pièce, ou de le décaler avec Contour décalé.
  • Détourer un relief sans dessiner son contour : dans un parcours Profil, cliquez directement le relief, dans la vue 2D ou dans la vue 3D. Son contour s’affiche en pointillés bleus et le bouton devient Calculer autour du relief. La profondeur se règle toute seule sur le bas du relief (haut du brut → haut du relief + épaisseur du relief, sans dépasser l’épaisseur du brut) ; vous pouvez la modifier. Le parcours suit le contour du relief et se recalcule quand vous le déplacez ou le modifiez (mettez-le à jour). Recliquez le relief pour le retirer ; vous pouvez aussi ajouter des vecteurs au même parcours.
  • Dans la vue 2D, un relief (STL, niveaux de gris, dôme, extrusion ou lissage) se manipule comme un vecteur, avec l’outil Sélection : un premier clic le sélectionne et ouvre ses réglages de position dans l’onglet Relief, et vous pouvez le glisser pour le déplacer ; un deuxième clic affiche les poignées : carrés pour redimensionner (coins : proportions gardées, Maj pour déformer ; côtés : une seule dimension), ronds pour tourner (Ctrl : par 15°) ; Ctrl redimensionne au millimètre. Suppr le retire. Un clic droit sur un relief, dans la vue 2D ou dans la vue 3D, ouvre son menu (parcours, contour, dupliquer, supprimer…).
  • Affichage : en 2D, tous les reliefs (STL, niveaux de gris, dômes, extrusions et lissages) s’affichent ombrés sous le dessin ; tout le relief se voit dans la vue 3D. Le résumé indique la profondeur du point le plus bas et prévient s’il dépasse l’épaisseur du brut. Un relief qui déborde du brut (après avoir réduit le brut, par exemple) reste affiché en entier, en 2D comme en 3D, mais seule la partie dans le brut sera usinée.

Les données du relief sont gardées dans le navigateur et enregistrées dans le fichier .copo : hauteurs de chaque relief, images, et maillage complet des modèles STL. Un projet envoyé à quelqu’un s’ouvre donc tel quel sur un autre ordinateur, sans le fichier STL d’origine, et on peut encore y changer l’orientation du modèle.

Formes créées à partir du dessin

Sélectionnez des vecteurs dans la vue 2D, puis cliquez sur l’un des trois boutons de Créer à partir du dessin. La forme est copiée dans le relief : modifier le dessin ensuite ne la change pas.

  • Dôme (une ou plusieurs formes fermées ; les formes intérieures font des trous) : la hauteur monte depuis le bord. Largeur du bord = 0 bombe jusqu’au centre (arête au milieu des formes allongées, comme dans Aspire) ; une valeur donne un arrondi de cette largeur puis un plateau.
  • Extrusion (un ou plusieurs vecteurs, ouverts ou fermés) : une moulure de la largeur choisie suit le tracé, extrémités arrondies.
  • Lissage (deux rails + un vecteur de profil, tous ouverts) : la section dessinée passe d’un rail à l’autre, mise à l’échelle de l’écart entre les rails. Le profil est le vecteur qui relie les deux rails, sinon le dernier sélectionné (modifiable par Vecteur de profil) ; sa corde va d’un rail à l’autre et sa hauteur réelle donne l’épaisseur Z ; Retourner le profil l’inverse si besoin. Sans troisième vecteur, la section est ronde ; Hauteur à la fin fait varier la hauteur du début à la fin (crosse, manche, bord bombé) et la case Hauteur proportionnelle à la largeur l’adapte à l’écart entre les rails.
  • Lissage à plusieurs profils : pour que la section change le long des rails, dessinez plusieurs profils en travers, chacun d’un rail à l’autre, à l’endroit où il doit s’appliquer (ses deux extrémités sur les rails). Sélectionnez les deux rails et tous les profils, puis Lissage : COPO reconnaît les rails (les vecteurs que touchent les profils), place chaque profil là où il croise les rails et fait passer la section progressivement de l’un au suivant, forme et hauteur comprises. Avant le premier profil et après le dernier, la section reste celle du profil le plus proche. La case Transition douce entre les profils (cochée par défaut) arrondit le passage d’une section à l’autre : pas de cassure au droit d’un profil, et la forme arrive à plat sur le premier et le dernier ; décochez-la pour une transition en ligne droite. Le panneau indique le nombre de profils et leur position en % de la longueur des rails. Pour déplacer un profil, déplacez son vecteur dans la vue 2D et recréez le lissage.
  • Profil du dôme et de l’extrusion : rond, angulaire (en pointe), plat ou doucine (en S). L’épaisseur Z, le décalage de la base, la combinaison et l’adoucissement se règlent comme pour les autres éléments.

Usiner le relief

Dans l’onglet Parcours, le type Relief propose deux opérations, chacune illustrée par une petite coupe : l’ébauche en escalier autour du relief, la finition qui suit la surface. Les stratégies ont aussi leur image : Niveaux Z (paliers à plat) et Balayage 3D pour l’ébauche, Balayage (allers-retours) et Décalage (passes qui suivent le contour) pour la finition. Sous la liste des reliefs à usiner, le volet Options avancées (ouvert par défaut) regroupe la limite d’usinage, avec une image qui montre en bleu la limite choisie (contour du modèle, contour du brut ou vecteurs sélectionnés), le décalage, la position de l’outil, la stratégie et les pas.

  • Ébauche : balayage par niveaux de Z avec une fraise droite (la plus grosse est proposée), chaque niveau descendant de la profondeur de passe, en laissant une surépaisseur (0,5 mm par défaut) pour la finition. Pas latéral par défaut : 40 % du diamètre. Entrée de l'outil : Rampe aller-retour par défaut (l'outil descend en suivant le début de la passe, sur la longueur de rampe calculée comme pour un profil, puis revient à son départ à pleine profondeur), Hélice (l'outil alèse un trou de 1,5 × Ø en descendant de la descente par tour choisie, au premier endroit de la passe où le cercle tient entièrement dans la limite d'usinage et dans la matière à enlever, puis rejoint le début de la passe ; sinon il entre en rampe) ou Plongée droite.
  • Finition : balayage parallèle qui suit la surface en tenant compte de la forme réelle de l’outil, sans jamais entamer le relief. Utilisez une fraise hémisphérique, une fraise conique à bout sphérique (définie par D, R et L) ou, pour les détails fins, une fraise de gravure à pointe plate (angle et diamètre de la pointe). Une fraise de gravure à bout rond se décrit comme une fraise conique à bout sphérique, avec les cotes de la boîte : diamètre de queue D, rayon en bout R, longueur d’usinage L ; COPO en déduit l’angle (D 6, R 1, L 20 : 5,99°). Pas latéral par défaut : 10 % du diamètre ; angle du balayage réglable et seconde passe croisée à 90° possible.
  • Reliefs à usiner : cochez les éléments dont le contour limite l’usinage (tous par défaut). Les hauteurs restent celles du relief complet.
  • Limite d’usinage : Contour du modèle (les reliefs cochés, sans le fond transparent des images), Contour du brut (tout le brut) ou Vecteurs sélectionnés (formes fermées sélectionnées dans la vue 2D) . Outil par rapport à la limite : bord de l’outil à l’intérieur (par défaut, la fraise ne dépasse pas le tracé) ou centre de l’outil sur la limite (la fraise déborde d’un rayon) ou bord de l’outil à l’extérieur (la fraise fait tout le tour du relief et en sort entièrement : c’est le choix habituel pour finir proprement le bord d’un relief, sans ajouter de décalage). Décalage du contour agrandit (valeur positive) ou réduit (négative) la limite, par exemple pour laisser de la place à un dégagement.
  • Stratégie : en ébauche, Niveaux Z (n’usine que sous chaque niveau, en tronçons) ou Balayage 3D (chaque ligne suit la surface sans descendre sous le niveau, moins de remontées) ; en finition, Balayage (lignes parallèles à l’angle choisi, passe croisée possible) ou Décalage (contours parallèles au bord de la limite, de l’extérieur vers l’intérieur, en avalant ou en opposition).

Les passes s’enchaînent en zigzag zone par zone et les liaisons courtes restent au ras de la surface, pour limiter les remontées et les trajets hors matière. Si le relief change après le calcul, le parcours l’indique en orange : ouvrez-le et cliquez sur Mettre à jour. Les fichiers de finition sont longs (des dizaines de milliers de lignes), comme dans tout logiciel de sculpture ; l’aperçu 3D rejoue l’ébauche puis la finition.

Parcours d'outils

En haut de l'onglet, les quatre boutons Profil, Poche, V-carve et Perçage créent un parcours : sélectionnez les vecteurs dans la vue 2D (même réglages ouverts), puis cliquez sur l'opération. Ses réglages prennent la place des boutons et de la liste dans le panneau, sans rien cacher de la vue 2D ni de la vue 3D ; la ligne Type : Profil · changer permet de changer d'opération. Cliquer un parcours de la liste ouvre ses réglages pour le modifier. La croix bleue en haut à droite, ou un clic droit dans le vide du dessin, les ferme et ramène la liste.

Tant que les réglages du parcours sont ouverts, le reste du dessin et les autres parcours sont estompés : seuls les vecteurs sélectionnés et le parcours en cours ressortent. Tout redevient normal à la fermeture. Au bas des réglages, une ligne d'état dit ce qui sera usiné, par exemple « 3 vecteurs sélectionnés (2 fermés, 1 ouvert) » ; elle passe en rouge s'il n'y a rien de sélectionné, et prévient quand une poche, un V-carving ou un perçage ignorera des vecteurs ouverts.

Les quatre types

  • Profil : Extérieur / droite (la pièce est conservée), Intérieur / gauche (le trou est évidé) ou Sur la ligne. Sur une ligne ouverte, Extérieur fait passer l'outil à droite du tracé et Intérieur à gauche, dans le sens où il a été dessiné (Dessin › Inverser le sens pour changer) ; « Sur la ligne » suit le trait ou passe à gauche ou à droite selon le réglage « Lignes ouvertes ». Sur une ligne ouverte décalée à droite ou à gauche, les entrées en rampe, en arc tangent et en arc en rampe s'appliquent aussi : l'arc entre et sort du côté de la matière enlevée.
  • Poche : quatre stratégies, sur une ligne d’icônes : Spirale int. → ext. (part du milieu et s’élargit jusqu’au bord), Spirale ext. → int. (suit d’abord le bord puis se resserre), Aller-retour (lignes parallèles à l’angle choisi, sans aucun tour du bord : bords légèrement festonnés ; la surépaisseur ne s’applique pas) et Aller-retour + contour (les mêmes lignes, puis un tour du bord pour le nettoyer). En spirale, s’il reste une bande trop large pour un seul passage au milieu (selon la largeur de la poche et le pas latéral), un passage de nettoyage est ajouté automatiquement. La reprise de matière (Options avancées) usine avec la fraise du parcours, la petite, les coins qu’une plus grosse n’a pas pu atteindre. Dans Après le parcours, choisissez la poche faite avant sur les mêmes vecteurs, par exemple « Poche 1 (Fraise droite 6 mm) » : sa fraise, sa profondeur et sa surépaisseur sont reprises. Ou choisissez Faire un parcours… : COPO ouvre la bibliothèque pour la grosse fraise et crée avant la reprise une ébauche liée, comme dans Aspire. Avec une surépaisseur, la grosse fraise la laisse ; la petite finit les parois, sauf avec « Ne pas enlever la surépaisseur », où les deux la laissent.
  • V-carving : la fraise en V suit l'axe médian du tracé ; elle descend là où le trait est large et remonte jusqu'à la pointe des coins. Les branches sont enchaînées dans l'ordre le plus court ; entre deux branches, la fraise passe tout droit en restant dans la gravure (à une profondeur sans risque, ou juste au-dessus de la surface) et ne remonte au Z de dégagement que si le trajet sort du motif. Les liaisons sont tracées en pointillé comme les déplacements, et la fraise en V ne repasse pas au fond là où les anneaux ou la fraise de dégagement ont déjà vidé la matière. Aux paliers suivants, elle redescend en rapide jusqu’à 0,2 mm au-dessus de ce qui est déjà creusé, puis plonge. Avec une fraise de dégagement, chaque palier commence par le nettoyage des coins, puis fait le contour (la paroi) ; on garde ainsi la profondeur de passe partout. Une profondeur maximale donne un fond plat. Avec une javelot ou une fraise à bout rond, la profondeur suit la vraie forme du bout : les coins sont arrondis au rayon du bout, les zones plus étroites que le bout ne sont pas usinées (en rouge dans la vue 2D, avec un avertissement), et le bout vide lui-même les fonds plats s'il n'y a pas de fraise de dégagement. Une fraise en V pointue fine (moins de 60° environ) ne vide pas un fond plat : ajoutez une fraise de dégagement. La profondeur de passe (celle de l’outil si la case reste vide) découpe la gravure en paliers, comme dans Aspire : les zones profondes sont creusées en plusieurs fois, sans changer le résultat final. La précision du calcul (0,1 mm par défaut) est l’écart entre les points qui servent à calculer l’axe médian : 0,05 mm pour les petites lettres. Des fraises de dégagement (fraises droites), choisies après la fraise en V avec + Ajouter une fraise…, peuvent vider les fonds plats : COPO les range de la plus grosse à la plus petite et ajoute, juste avant le V-carve, un parcours « dégagement » lié par fraise ; chacune ne reprend que ce que la précédente n’a pas pu enlever, et la fraise en V ne reprend que le bord. Ces parcours se règlent depuis le V-carve. Si vous supprimez le V-carve, COPO demande s’il faut les garder comme parcours indépendants. Renommer le V-carve ne touche pas à ses parcours de dégagement.
  • Perçage : un trou au centre de chaque forme fermée, avec débourrage et temporisation au fond si besoin (0 = sans). Le débourrage se remplit tout seul avec celui de l’outil, réglé dans la bibliothèque d’outils selon le matériau : aluminium, cuivre, laiton (copeaux longs) 0,5 × D ; aciers, fontes et plastiques 1 × D ; bois et MDF 2 × D. Avec une fraise droite, les cercles plus grands qu’elle peuvent être usinés en hélice au diamètre dessiné (case décochée par défaut) ; l’option n’apparaît pas avec un foret, une fraise hémisphérique ou une fraise en V. Si elle est décochée, un avertissement orange signale les cercles plus grands que la fraise, qui seront percés au diamètre de la fraise (pratique quand on dessine de grands cercles juste pour mieux voir et sélectionner les perçages). Avec un foret, chaque trou est percé au diamètre du foret ; COPO indique la longueur de la pointe à ajouter pour un trou débouchant.
  • Filetage : taraudages et vis usinés à la fraise à fileter (monodent, 60°), centrés sur chaque cercle sélectionné. Réglez intérieur (taraudage) ou extérieur (vis), le pas, le diamètre nominal (0 = celui du cercle : dessinez le cercle à 8 mm pour du M8), le sens du filet et le nombre de passes radiales ; la longueur filetée est la profondeur de coupe. COPO affiche le diamètre de perçage préalable (Ø nominal − pas, par exemple Ø6,75 pour M8 × 1,25). L’outil travaille toujours en avalant, un tour d’hélice par pas, avec une entrée et une sortie tangentes en demi-cercle ; l’avance indiquée est celle du tranchant et COPO la corrige au centre de l’outil. Pour une vis, dégagez d’abord la matière autour du cylindre. Deux fraises à fileter (Ø4 et Ø8 mm) ont été ajoutées à la bibliothèque, avec des réglages estimés.

Recalcul des parcours : quand le dessin change, COPO ne recalcule que les parcours concernés (ceux dont les formes ou les réglages ont changé) ; annuler et rétablir retrouvent les calculs déjà faits. Un calcul long se fait en tâche de fond, avec une barre de progression : vous pouvez continuer à dessiner pendant ce temps (si le dessin change entre-temps, le parcours est recalculé ensuite).

  • Automatique (par défaut, Paramètres › Général) : un parcours long à calculer (plus d’une demi-seconde) attend une pause d’environ 1,5 s sans modification ; vous enchaînez les retouches sans attendre, et le parcours porte le badge ⟳ en attendant. Ouvrir l’onglet G-code le recalcule tout de suite. Si les recalculs sont souvent longs, COPO propose une fois de passer en manuel.
  • Manuel : les parcours touchés sont marqués ⟳ et gardent leur ancien tracé jusqu’au clic sur Recalculer les parcours (sous la liste des parcours).
  • Dans les deux modes, un point orange sur les onglets Parcours et G-code signale des parcours pas à jour ; le bandeau de l’onglet G-code a un bouton Recalculer maintenant. L’export du G-code, la fiche de gamme et la simulation recalculent d’abord ce qui n’est pas à jour (en manuel, COPO le propose : Recalculer et continuer). Le bouton Recalculer tous les parcours reste disponible.

Options avancées : sous le sens de coupe, ce volet repliable (fermé par défaut, COPO se souvient de votre choix) regroupe la surépaisseur et son retrait, la projection sur le relief, l’entrée de l’outil et la longueur de rampe, la reprise de matière (poche), et pour le perçage l’hélice, le débourrage et la temporisation. La surépaisseur est à 0 par défaut.

Passes, surépaisseur et sens de coupe

Prof. départ (D) et Prof. coupe (C), comme dans Aspire : l'usinage commence à la profondeur D sous la surface (par exemple au fond d'une poche déjà usinée) et descend de C à partir de là ; le fond est donc à D + C. Pour un profil ou une poche, C peut valoir 0 : une seule passe à la profondeur D (surfaçage, ou fraise posée sur le relief avec la projection). Laissez D à 0 pour partir de la surface. Une valeur négative fait commencer au-dessus de la surface : les premières passes se font à vide, utile si le brut est plus épais que prévu ou sa surface irrégulière (D = −2 et C = 5 : départ 2 mm au-dessus, fond à 3 mm de profondeur). En V-carving, la fraise calcule le motif comme si la surface était à D, ce qui sert notamment à l'incrustation. Le petit schéma à côté des champs rappelle ce que sont D et C.

Projeter sur le relief (profil, poche, V-carving) : le parcours suit la surface de tous les reliefs visibles de l’onglet Relief au lieu du dessus plat du brut (inutile de sélectionner le relief : sélectionnez seulement les vecteurs du parcours) ; les profondeurs D et C se mesurent alors depuis le relief. La hauteur de contact tient compte de la forme de la fraise (en V, hémisphérique, droite), pour graver un motif ou une lettre sur une surface bombée. En dehors du relief, le parcours reste mesuré depuis le dessus du brut. Face 1 seulement ; si le relief change, la liste signale qu’il faut recalculer le parcours.

La profondeur de coupe est répartie en passes de la profondeur choisie. Une surépaisseur laisse un peu de matière sur les parois pendant l'ébauche ; elle est retirée à la dernière passe ou par une passe de finition sur toute la hauteur, ou laissée en place (Ne pas enlever la surépaisseur) pour la retirer avec un autre parcours de finition, par exemple avec une autre fraise. Le sens de coupe est avalant ou en opposition.

Entrée de l'outil

EntréeComportement
Rampe aller-retourL'outil descend en avançant, revient au départ à pleine profondeur puis fait le tour. Chaque passe commence et finit au même point. Réglage par défaut. Laissée vide, la longueur de rampe est calculée pour descendre la passe sous l'angle conseillé pour le matériau des outils du projet : 10° pour le bois tendre, le MDF et les plastiques, 5° pour le bois dur, 4° pour l'aluminium et le laiton (longueur = passe ÷ tan(angle), jamais moins de 1,5 × Ø) ; le champ affiche la valeur et l'angle. Pour le contreplaqué (3 à 5°), saisissez une rampe plus longue.
Rampe continueL'outil descend en avançant et enchaîne le tour ; la portion de rampe est recoupée à la fin.
Arc tangent, arc en rampeEntrée et sortie en arc sur le contour, pour éviter une marque sur la paroi finie.
HéliceL'outil descend en spirale, idéal pour les poches et les trous. Laissés vides, le diamètre de l'hélice vaut 1,5 × Ø (l'outil alèse un trou une fois et demie plus large que lui) et la descente par tour suit l'angle de rampe du matériau ; les deux champs affichent les valeurs calculées.
Plongée droiteDescente verticale, pour les fraises qui coupent en bout ou le V-carving.

La bulle ⓘ à côté de Entrée de l'outil résume les repères : diamètre d'hélice de 1,5 à 2 × Ø dans le bois (1,2 à 1,8 × Ø dans le métal), angle de rampe de 5 à 15° dans le bois tendre et le MDF, 3 à 8° dans le bois dur, 3 à 5° dans le contreplaqué et l'aluminium, 1 à 3° dans l'acier ; avance en rampe à 50 à 70 % de l'avance de coupe. Longueur de rampe = profondeur ÷ tan(angle) : 5 mm à 10° donnent environ 28 mm. Sous 1,2 × Ø, l'hélice travaille presque en plongée ; au-delà de 2 × Ø, une fraise qui ne coupe pas au centre laisse un téton. Les valeurs du fabricant priment, et une fraise qui ne coupe pas au centre ne doit jamais plonger droit.

Rampes et hélices descendent à 60 % de l’avance de coupe. Dans les vues 2D et 3D, ces descentes sont tracées en orange par-dessus le parcours, pour voir où l’outil entre dans la matière.

Ponts d'attache

Les ponts maintiennent une pièce détourée jusqu'à la fin. Réglez leur nombre par contour, leur longueur et leur épaisseur, plats ou triangulaires (plus faciles à casser). Placer à la main dans la vue 2D… permet d'ajouter un pont d'un clic sur le parcours, de le glisser ou de le retirer.

Texte et V-carving

Choisissez une police dans la liste du bloc Texte : polices installées (Chrome et Edge) ou votre dossier de polices (bouton Ouvrir un dossier de polices… du bloc ; l’icône ⓘ explique où les ranger), avec aperçu. Deux cases en haut de la liste, Polices de COPO et Polices de l'ordinateur, raccourcissent la liste ; le choix est mémorisé. Prenez l'outil Texte T : un contour en pointillé suit le pointeur et montre où le texte sera posé. Le placement se choisit sur cinq illustrations : Droit (cliquez dans la vue 2D), Au-dessus de la courbe, Sur la courbe ou Sous la courbe (cliquez sur une ligne, un arc, un cercle, un contour…) et Entre deux courbes ; un encadré bleu dit ce qu’il faut cliquer. Tant que le texte placé (ou repris avec Modifier le texte) reste sélectionné, cliquer une autre courbe (ou, en placement Droit, un autre point) le déplace ; Maj + clic en place un second. Sur une courbe, réglez l’alignement (gauche, milieu ou droite de la courbe ; pour un contour fermé, par rapport au point cliqué), les lettres (alignées à la courbe ou gardées verticales), Texte de l’autre côté de la courbe (pour écrire à l’intérieur d’un arc, par exemple) et l’espacement entre les lettres (aussi pour le texte droit). Tant que l’outil Texte reste actif, chaque réglage modifie en direct le texte que vous venez de placer : texte, police, hauteur, placement, alignement… plus besoin d’effacer et de recommencer. Pour reprendre un texte plus tard, sélectionnez-le : l’icône T du bloc Sélection rouvre ses réglages. En placement Entre deux courbes, cliquez la courbe du bas (la ligne de base) puis celle du haut : les lettres s’étirent pour remplir l’espace entre les deux, comme une enveloppe (deux arcs pour une enseigne bombée, par exemple). Le décalage éloigne le texte de la courbe (sur une courbe) ou garde une marge avec chacune des deux courbes (entre deux courbes). Le texte devient des vecteurs groupés, prêts pour le V-carving, la poche ou le profil.

Polices à trait unique

COPO est livré avec une soixantaine de polices à trait unique (Hershey, EMS, Cutlings, Relief SingleLine, Routed Gothic…), rangées dans le dossier fonts/trait-unique et proposées en tête de la liste des polices, avec aperçu. C'est le plus rapide pour les numéros de pièce, les plaques et les repères. Quand la sélection ne contient que des traits ouverts, Usiner… propose directement ce profil. Lutherie : touche et incrustation

Touche de guitare

Extensions › Touche de guitare… dessine la touche, le sillet à gauche, centrée sur le brut. Réglez le diapason, le nombre de frettes, la largeur au sillet et la seconde largeur, à la 12e case ou au bout du diapason, le dépassement après la dernière frette, les cases avec un repère et un double repère (listes de numéros) et le diamètre des repères. Le trait du diapason (case cochée par défaut) trace l'axe du sillet jusqu'au chevalet, avec un repère à chaque bout, pour placer le chevalet. Avec la case Frette zéro, une frette 0 est tracée à l'origine du diapason (avec la même distance au bord que les autres) et la touche commence avant elle, à la distance réglée dans Début de touche → frette zéro ; la largeur « au sillet » est alors celle de la frette zéro. La distance frettes – bord arrête les traits de frettes avant le bord de la touche (0 = frettes traversantes). L'aperçu se met à jour en direct. La fenêtre s'ouvre à côté du panneau de gauche, comme les réglages des parcours, et se déplace par son titre.

Position des frettes

COPO utilise la formule exacte du tempérament égal, celle des calculateurs de frettes de référence :

dn = L − L / 2n/12  soit  dn = L × (1 − 2−n/12)

où L est le diapason, n le numéro de la frette et dn la distance du sillet à la frette. Chaque frette raccourcit la corde d'un demi-ton, d'un facteur 21/12 ≈ 1,05946 ; la 12e frette tombe exactement au milieu du diapason. La « règle du 17,817 » donne le même résultat ; l'ancienne règle du 18, moins juste, n'est pas utilisée. Aucune compensation n'est appliquée aux frettes : la justesse se règle au chevalet, que l'on recule de quelques millimètres par rapport au trait du diapason.

Incrustation en V (inlay)

Sélectionnez le motif (formes fermées), puis Dessin › Incrustation en V (inlay)…. Les réglages s’ouvrent dans le panneau de gauche, avec un schéma coté comme dans Aspire : a profondeur de poche, g jeu pour la colle au fond, b hauteur du mâle sous le support (il doit dépasser a − g : l’écart restant sera raboté), c débord du support, et un préfixe facultatif pour les noms des parcours, nommés calque_fonction_fraise : femelle_degagement_6mm, femelle_vcarve_90deg, mâle_degagement_6mm… Choisissez la fraise en V (bouton Bibliothèque… pour toute la bibliothèque) et, si vous voulez, des fraises de dégagement droites qui vident d’abord les fonds plats (plus rapide sur les grands motifs). Comme dans Aspire, vous pouvez en ajouter plusieurs (+ Ajouter une fraise…) : COPO les range de la plus grosse à la plus petite ; la plus grosse vide les fonds plats, chaque suivante est une reprise de matière liée à la précédente et ne reprend que ce qu’elle n’a pas pu enlever. Le débord c est automatique si la case reste vide ; la case Créer les parcours d’outils peut être décochée pour ne dessiner que la pièce mâle. COPO crée :

  • un V-carving femelle du motif dans votre pièce ;
  • la pièce mâle : le motif en miroir entouré d'un cadre, sur le calque « mâle » (le cadre n’est pas groupé avec le motif : c’est la limite du dégagement du mâle, l’agrandir ou le réduire modifie ce parcours ; le motif en miroir sert de repère, les parcours utilisent la forme de travail), avec un V-carving qui démarre à la profondeur de la poche moins le jeu et descend de l’écart de surface. Tous les calques (« mâle », « dégagement », « incrustation (calcul) ») et tous les parcours sont créés visibles : pour usiner une seule pièce, masquez les parcours de l'autre (icône œil de la liste) avant d'enregistrer le G-code.
  • avec une fraise de dégagement, une poche « dégagement » avant chaque V-carving, là où le V atteindrait sa profondeur maximale. Avec une javelot ou une fraise à bout rond, femelle et mâle sont usinés sur une même forme de travail, dont les pointes et les coins rentrants sont arrondis au rayon du bout : les deux pièces s'emboîtent jusqu'au fond (votre dessin n'est pas modifié). La fraise en V ne repasse pas sur les fonds vidés par le dégagement : elle fait la paroi, puis seulement ce que la fraise de dégagement, à cause de son diamètre, n’a pas pu atteindre (pointes, passages étroits). Pour le mâle, le dégagement vide tout jusqu’au cadre (paroi droite), à la profondeur où travaille la fraise en V, et la fraise en V ne fait plus que la paroi en pente du motif, par paliers, plus les coins que la fraise de dégagement n’atteint pas : elle ne touche ni au cadre ni aux fonds plats. Le débord automatique s’élargit pour que le cône de la fraise reste dans le cadre.

Retournez le mâle, collez-le dans la femelle, puis rabotez ou poncez le surplus. Le réglage Profondeur de départ du V-carving est aussi disponible à la main dans le formulaire des parcours.

Incrustation en poche (fraise droite)

Sélectionnez le motif (formes fermées), puis Extensions › Incrustation en poche (inlay)… ou, au clic droit, Incrustation › En poche. Les réglages s’ouvrent dans le panneau de gauche. Choisissez la fraise droite (le bouton Bibliothèque… donne accès à toute la bibliothèque d’outils), le jeu pour la colle (0,1 mm par défaut) et la façon de faire la pièce mâle (case Pièce mâle sur support). Un petit schéma coté, comme dans Aspire, montre les cotes à remplir : a profondeur de poche, b hauteur du mâle (sous le support, ou épaisseur de la pièce sans support) et c débord du support (automatique si la case reste vide). La case Créer les parcours d’outils (cochée par défaut) peut être décochée pour ne créer que les contours. Pour les grandes poches, cochez Ébaucher avec une plus grosse fraise : COPO conseille ou non l’ébauche selon la largeur de la poche et la fraise principale, et propose une fraise (du projet, sinon de la bibliothèque). La grosse fraise vide alors la poche et le fond du bouchon, puis la fraise principale ne reprend que les angles et les passages étroits (reprise de matière) : sur une poche de 60 × 40 mm, le temps est divisé par près de trois.

Une fraise droite ne fait pas d’angle plus vif que son rayon. COPO calcule donc un contour commun dont tous les angles, rentrants comme saillants, sont arrondis au moins au rayon de la fraise : la poche et la pièce rapportée s’usinent exactement sur ce tracé et s’emboîtent sans retouche. L’aperçu montre ce contour en bleu, le dessin d’origine en pointillés rouges, et la part de surface modifiée ; un avertissement signale les parties plus fines que la fraise, qui disparaissent.

  • Pièce mâle sur support (case cochée, par défaut) : le motif est usiné en miroir, en relief, dans une planche épaisse, sur une hauteur b plus grande que la poche a : une fois collée, la planche reste à b − a au-dessus de la pièce, ce qui laisse la place du trait de scie. Collez la planche retournée dans la poche, puis sciez ou rabotez le surplus. Tous les morceaux du motif restent liés et se posent d’un coup.
  • Pièce mâle sans support (case décochée) : le motif est découpé dans une planchette d’épaisseur b, avec des ponts d’attache. La profondeur de découpe vaut b si la case reste vide ; mettez un peu plus (b + 0,2 mm, par exemple) pour traverser franchement si votre martyr le permet. Prenez b égal à a pour une pièce à fleur, un peu plus si vous voulez poncer après collage ; COPO prévient si b est plus petit que a. Cassez les ponts, poncez, puis collez la pièce dans la poche.

Supprimer un parcours de l’incrustation supprime aussi les contours qu’il avait créés (le dessin d’origine est conservé). COPO crée la poche sur le calque « Incrustation en poche · femelle » et la pièce rapportée à droite du motif, sur le calque « Incrustation en poche · mâle ». Les deux parcours sont visibles et partent dans le G-code ; masquez-en un (œil) si vous usinez les pièces séparément.

Boîte à entures

Le menu Extensions › Boîte à entures… ouvre ce module, qui dessine une boîte assemblée par tenons droits, à la façon du « Box Creator » de Vectric. Réglez les dimensions extérieures (largeur X, profondeur Y, hauteur Z), l'épaisseur du matériau (celle du brut par défaut), la largeur des tenons (leur nombre, toujours impair, s'en déduit), le jeu d'assemblage (0,1 à 0,2 mm dans le bois), la fraise de découpe, l'assemblage du dessus (à entures pour une boîte fermée, par défaut, ou posé à plat pour un couvercle amovible) et les faces à usiner (Dessus, Fond de boîte, Côtés, Bouts). Les tenons sont répartis à égalité entre les coins : la zone de coin, de l'épaisseur du matériau, n'existe que là où un autre panneau s'assemble, si bien qu'une boîte ouverte garde le même pas jusqu'en haut. Les tenons peuvent être plus étroits que l'épaisseur ; COPO prévient si les creux deviennent plus étroits que la fraise. L'option Dégagements dogbone ajoute au fond de chaque creux un arc du diamètre de la fraise, pour que les tenons à angles vifs entrent.

L'aperçu montre les panneaux posés à plat. Créer la boîte les place sur le brut, espacés pour la fraise : usinez-les en profil extérieur, avec des ponts d'attache. Les volumes des panneaux s'emboîtent exactement : aucun recouvrement ni manque aux coins.

Graduations rotatives

Dans un projet rotatif, Extensions › Graduations rotatives… dessine des traits équidistants autour du cylindre : graduations, vernier, cannelures, dents d’engrenage. Les traits sont toujours parallèles à l’axe du cylindre choisi dans l’onglet Projet (horizontaux si le cylindre est le long de X, verticaux s’il est le long de Y) et répartis sur le tour (π × D).

  • Nombre de divisions et étendue : à 360°, autant de traits que de divisions sur le tour complet. Sous 360°, les divisions couvrent l’étendue avec un trait à chaque bout ; pour un vernier au dixième, par exemple, 10 divisions sur 9°.
  • Angle du premier trait : 0° est la ligne de l’origine, comme les repères 0°, 90°, 270° de la vue 2D.
  • Position et longueur : comme dans le bloc Sélection, on choisit le point de référence du trait (début, milieu ou fin), puis sa position X (ou Y) par rapport à l’origine et sa longueur.
  • Traits plus longs : un trait moyen tous les n traits et un trait long tous les m traits, chacun avec sa longueur ; ils partent du même point de référence. Numéro du premier trait décale ce comptage.

L’aperçu montre la feuille déroulée et le pas, en degrés et en millimètres sur la surface. Créer les traits les pose en groupe sur le calque actif ; usinez-les en V-carving ou en profil « sur la ligne ».

Imbrication

Dessin › Imbrication… ouvre le bloc dans l'onglet Dessin. Sélectionnez les pièces (sans sélection, tout le dessin est pris) et réglez le nombre d'exemplaires, l'espacement, la marge du panneau, les rotations permises et la précision. COPO place les pièces selon leur forme réelle, les plus grandes d'abord, le plus en bas à gauche possible. Un groupe ou un texte reste d'un bloc. Les pièces qui ne tiennent pas restent sélectionnées et le taux d'occupation du panneau s'affiche.

Pour du détourage, prenez un espacement au moins égal au diamètre de la fraise. Ctrl+Z annule l'imbrication si le résultat ne convient pas.

Usinage double face

  1. Mettez les vecteurs de la face du dessous sur un calque réglé sur F2 (bouton F1/F2 dans la liste des calques). Dessinez-les vus du dessus, par transparence.
  2. Choisissez le retournement : autour de l'axe X (haut ↔ bas) ou de l'axe Y (gauche ↔ droite).
  3. Les parcours de la face 2 sont calculés sur la géométrie retournée ; le sens de coupe est conservé.
  4. Dans le G-code, la face 1 est suivie d'une pause M0 : retournez la pièce, refaites X0 Y0 Z0 au même point et relancez.

L'aperçu 3D montre les deux faces ; l'option Face 2 en haut présente la pièce retournée.

Vues 2D et 3D

Les boutons 2D et 3D en haut de l’écran fonctionnent comme deux interrupteurs : 2D seule (le dessin occupe toute la zone), 3D seule (le relief), ou les deux à la fois. Quand les deux vues sont affichées, les boutons voisins les placent côte à côte ou l’une au-dessus de l’autre, et la séparation entre elles se fait glisser pour agrandir l’une ou l’autre (double-clic : moitié-moitié). L’onglet Relief affiche la vue 3D automatiquement.

La vue 3D montre le relief dans le brut (en filaire), avec le dessin et le repère. La vue est en projection orthogonale (sans perspective), pratique de face ou de côté. Clic droit maintenu : tourner (autour du point sous le pointeur, sans limite, on peut passer sous la pièce) ; clic molette maintenu : déplacer ; molette : zoom vers le pointeur ; double-clic : tout le brut ; un clic gauche sélectionne. Comme dans Fusion, FreeCAD ou Tinkercad ; la souris se règle dans Paramètres › Vues 3D. En haut à droite : le cube d’orientation. En bas, des barres d’icônes comme dans la vue 2D : à gauche, afficher ou masquer le dessin, le repère, le brut et les parcours d’outils (passes à la couleur de leur type, déplacements rapides en gris) ; au centre, les outils de transformation ; à droite, Tout voir (relief). Le brut et les parcours sont affichés à chaque ouverture de COPO. Si vous masquez les parcours, celui que vous survolez dans la liste de l’onglet Parcours, ou celui que vous êtes en train de régler, reste visible en 3D.

Les vecteurs du dessin se sélectionnent aussi dans la vue 3D : cliquez sur un trait (le curseur devient une main). La sélection est la même dans les deux vues, en bleu ; Maj + clic ajoute ou retire un vecteur, un clic dans le vide désélectionne. Pratique pour choisir le contour d’un modèle STL avant de créer son parcours.

À l’ouverture de COPO, la vue 2D et la vue 3D sont affichés côte à côte. La vue 3D s’ouvre aussi d’elle-même avec les onglets Relief et Parcours. Si vous l’avez fermée avec le bouton 3D, COPO respecte ce choix jusqu’au prochain chargement de la page.

Transformer un relief en 3D. Cliquez un élément dans la vue 3D pour le sélectionner (coins de sa boîte en surbrillance ; la sélection est la même dans la vue 2D et dans la liste). La barre du bas propose trois outils, avec les cotes affichées en haut à gauche :

  • Déplacer : tirez les flèches X, Y ou Z (Ctrl : au millimètre). En Z, le haut du relief s’accroche au dessus du brut et le bas au fond ; en X et Y, les bords s’accrochent aux bords du brut.
  • Tourner : tirez le cercle bleu (autour de Z) ; pour un STL, les cercles rouge et vert le font aussi pivoter autour de X et de Y (Ctrl : par 15°, Ctrl + Maj : par 1°).
  • Redimensionner : tirez un coin pour agrandir en gardant les proportions (Maj ou la case « Garder les proportions » décochée : librement), un côté pour changer seulement la largeur ou la longueur, ou le rond bleu au-dessus pour l’épaisseur : le haut monte ou descend, le bas reste en place. Ctrl fait avancer au millimètre près.
  • Les deux derniers boutons posent le relief sur le fond du brut ou alignent son haut sur le dessus.

Chaque transformation s’annule avec Ctrl+Z ; le panneau du relief garde les valeurs exactes.

Aperçu 3D

Finesse : la simulation ne calcule que la zone réellement usinée (le reste du brut est affiché plein) ; plus la zone est petite, plus le rendu est fin. Le réglage Résolution (Standard, Haute ou Très haute : 0,5, 1,5 ou 3,5 millions de points) augmente encore la finesse ; la résolution utilisée s'affiche en bas de la fenêtre. Une simulation longue se calcule en tâche de fond : la fenêtre s’ouvre tout de suite sur le brut (Calcul de la simulation… en bas) et la lecture devient disponible à la fin du calcul.

L'aperçu simule l'enlèvement de matière dans l'épaisseur réelle du brut, y compris les trous débouchants. Les boutons de lecture rejouent l'usinage : retour au début, pas en arrière, lecture / pause, pas en avant et aller à la fin ; un pas correspond à un déplacement de l'outil. Au clavier : flèches gauche et droite, Début, Fin et Espace. Le curseur permet d'aller à n'importe quel instant. Le temps écoulé et le temps total s’affichent en haut à gauche de la vue ; le bouton Tout voir est en bas à droite, comme dans les autres vues, et la croix en haut à droite ferme l’aperçu. L'aperçu demande WebGL 2 (Chrome, Edge ou Firefox récents).

Cube d’orientation (coin haut droit) : il tourne avec la vue et indique les faces (Dessus, Avant, Droite…) et les axes X, Y, Z. Cliquez une face pour la vue correspondante (Dessus = vue de plan, comme le dessin), ou un coin pour une vue isométrique. L’outil affiché reprend sa forme : fraise droite, hémisphérique, en V, foret ou fraise à fileter (dent à 60° en bout, col dégagé). Les filets d’un filetage apparaissent dans l’aperçu au fil de la dernière passe (profil ISO à 60°), dans le trou ou autour de la vis.

Relief et pièce finie : la case Relief superpose le relief dessiné (un maillage de lignes à sa hauteur réelle) pour le comparer à la matière usinée. La case Pièce finie seule cache les chutes : la matière reliée au bord du brut sans passer par une découpe sur toute l’épaisseur disparaît, et il ne reste que la ou les pièces détourées, comme sorties de la machine. Les ponts d’attache ne relient pas la pièce à la chute (il en reste un petit talon visible). S’il n’y a aucune pièce détourée, tout le brut reste affiché.

Trajectoires en 3D

Courbes et arcs G2/G3. COPO n'envoie pas les courbes de Bézier telles quelles à la machine : les parcours sont calculés en petits segments, puis, si « Arcs G2/G3 » est coché, les portions circulaires sont reconnues et écrites en vrais arcs G2/G3 (fichier plus court, mouvement plus fluide). Un cercle dessiné avec l'outil Cercle ou un tracé lissé en mode Arcs donne des arcs exacts ; une courbe libre est approchée par une suite d'arcs et de droites, dans la tolérance.

Vérifiez toujours le G-code par un passage à vide, outil au-dessus du brut, avant d'usiner.

Unités : millimètres ou pouces

Dans l'onglet Projet, bloc Unités, choisissez les Unités de longueur (millimètres ou pouces) et les Unités d'avance (mm/min, mm/s ou in/min). Le choix s'applique partout : dessin, règles, grille (1/16, 1/8, 1/4 et 1 pouce), coordonnées, cotes, outils, parcours et fiche de gamme. En pouces, une option affiche les valeurs en fractions (au 1/64) et une autre écrit le G-code en pouces (G20) pour les contrôleurs réglés ainsi.

Le projet reste enregistré en millimètres : on peut changer d'unité à tout moment sans rien déformer, et un projet s'ouvre correctement chez quelqu'un qui travaille dans l'autre unité. Le choix est gardé en mémoire dans le navigateur.

Fiche de gamme

Le bouton Fiche de gamme… de l'onglet G-code (aussi dans le menu Usinage) prépare une fiche de réglage de deux pages pour l'atelier. Indiquez le nom de la pièce, la matière et vos remarques ; la fiche contient :

  • le brut, l'origine X0 Y0, le zéro Z, le retournement et le post-processeur ;
  • un résumé : temps estimé, profondeur maximale, emprise usinée depuis l'origine, longueur de coupe et volume de matière enlevée ;
  • la vue 2D de chaque face avec les parcours, l'origine et les cotes du brut, et deux vues dimétriques de la simulation (face 1 et face 2) ;
  • l'ordre de montage des outils, puis le tableau des parcours : opération, outil, profondeur, passes, surépaisseur, entrée, ponts, avance, plongée et temps ;
  • les points de vigilance détectés (usinage qui traverse le brut, détourage sans ponts, passe trop profonde, usinage hors du brut, parcours masqués) ;
  • une liste de contrôle avant de lancer, une zone de remarques et des cases de visa.

Enregistrer en PDF (dans la fenêtre de la fiche, ou directement Fichier › Enregistrer la fiche de gamme en PDF sans l'ouvrir) crée un fichier PDF au format A4, découpé en pages sans couper les tableaux ni les images, prêt à imprimer ou à envoyer. Le PDF est une image de la fiche (texte non sélectionnable) ; pour un PDF avec du texte, utilisez Imprimer puis « Enregistrer au format PDF » du navigateur. Vous pouvez aussi garder le fichier HTML avec le G-code. Les réglages de la fiche sont enregistrés avec le projet.

Your first job in six steps

  1. Set up the projectProject tab: stock size and material, X0 Y0 origin point, Z zero (top of stock or table), units and machine.
  2. Draw or importDraw with the icons of the Drawing tab, import an SVG, DXF, PDF or AI file or an image (the Import icon in the Create group, or the File menu) or type some text.
  3. Check your toolsChoose the material in the Project tab, then check in the Tool library (Toolpaths tab) the speed, feed, pass depth and stepover of each tool.
  4. Create the toolpathsSelect vectors in the 2D view, open the Toolpaths tab, choose Profile, Pocket, V-carve or Drilling, adjust, then click Calculate.
  5. Check in 3DThe Machining simulation button (Toolpaths tab) or Machining › 3D machining preview shows the machined stock. Play the job back to spot a wrong depth or tool.
  6. Save the G-codeG-code tab: choose the post-processor, then Save G-code. Always do a dry run before cutting.

The interface

The window reads from left to right, in the order you work.

First launch: a welcome screen offers a quick tour (six bubbles on the main areas), the sample project or an empty project. Then, the first time you open each tab, one or more tips show the essentials. Skipping the tour also turns tips off. Use Help › Quick tour to see it again and Help › Show tips again to bring the tips back; the “Don’t show at startup” box hides the welcome screen.

  • Save button (floppy disk, left of 2D/3D): the first time it asks where to save the project; after that it simply overwrites the same file (like Ctrl+S). A blue dot shows unsaved changes.
  • Menu bar: File, Edit, Drawing, Machining, Extensions and Help. The Drawing menu sorts its commands into five framed categories: Groups, Combine, Vectors, Corners and Arrange. The Extensions menu gathers the modules that create drawings and toolpaths in one go: guitar fretboard, V inlay, pocket inlay, finger-joint box and rotary graduations. The Help menu opens this guide, lets you report a bug and shows the licence. The FR / EN buttons, at the far right of the bar, switch the interface language; the button next to them puts COPO in full screen (Esc to leave).
  • Drawing tab: at the top, a grid of icons gathers every drawing function in two columns: on the left Selection and Library, Create, Arrange; on the right Measure, Modify, Combine; each with a tooltip and a shortcut letter. Just below appears what you need: the settings of the chosen tool (with a hint and a small diagram), the form of the clicked function (Align, Array copy, Nesting, Images…), or the Selection block when a vector is selected. Greyed icons need a selection first. Layers stay at the bottom. Esc closes the open function.
  • Workspace: the stock in beige, rulers in millimeters, the grid and the origin (X and Y arrows).
  • Left panel with five tabs: Project, Drawing, Relief, Toolpaths and G-code. They are numbered 1 to 5 in the usual order of work. In the Project and Toolpaths tabs and in the tool library, small diagrams show what each setting does (depth, allowance, cut direction, tool entry, tabs, tool shape, Z zero…) and update with your choices.
  • Workspace bar, floating at the bottom left of the 2D view (cursor coordinates relative to the origin show at the top left of the 2D view, on a transparent background, like the 3D view information): two groups of on/off icons (their name shows on hover). Snap (magnet): grid and its spacing, vectors, guides, and the settings button that opens Snap settings just above it. Show (eye): grid, toolpaths, removed material, overlapping lines. An active button has a blue outline. At the bottom right, the Fit all button fits the view to the stock and drawing; the 3D view has the same bars in the same places.
  • Tooltips: rest the mouse a quarter of a second on a button or setting to see what it does. The tooltip disappears as soon as the mouse leaves, and shows straight away on the next button while you explore. The ▲ ▼ arrows in the toolpath list change the machining order. In the toolpath list only the name is shown: the operation, tool, time and any warnings (! badge) appear on hover.
  • Math in fields: in any number field, type an operation with + - * (or x) / and parentheses, for example 595-140, 73.694/2 or (10+5)*3: the result replaces it on Enter or when leaving the field.
  • Toolpath names: a new toolpath is named layer_function_tool, for example female_clearance_6mm, female_vcarve_90deg or F2_bottom_pocket_6mm on side 2. As long as you have not changed it, the name follows the settings (another tool, another function). To rename a toolpath, double-click its name in the list (or F2): nothing is recomputed. In the form, if only the name changes, the toolpath is not recomputed either.
  • Three levels of help (1.283): under each setting, a short line says what to do. The ⓘ icon opens a bubble with the details (why, when, shortcuts): hover over it, or tap it on a tablet; its “Learn more” link opens the matching section of this guide. Technical words (ramp, tabs, stepover, peck, allowance…) show their definition when you hover over them, with no icon or underline; on a tablet, tap the word. Warnings state the consequence and the fix, for example “Risk of breaking the tool: reduce the pass depth”.

A vector is selected by clicking on its line (not inside it), so stacked vectors stay reachable. An already selected vector can be moved by dragging from inside.

Right click (Select tool): on a vector, in the 2D view as in the 3D view, it selects it and opens a menu next to the pointer. On a vector: Machine (Profile, Pocket, V-carve, Drilling), Duplicate, Group, Weld, Offset…, Mirror…, Rotation…, Center on the stock, Create a relief (Dome, Extrusion), Move to layer, Copy to layer and Delete. On an image: vectorize, turn into a relief, fit, center, stacking order, lock, delete. On a relief: roughing, finishing or profile toolpath, outline, duplicate, fit, center, hide, delete, and in 3D move, rotate, resize, drop to the bottom or align to the top. On empty space in the 2D view, right click closes the current tool or settings and deselects, without a menu; on empty space in the 3D view: fit all, top view, front view. With the pen or another drawing tool, right click still ends the path; in 3D, right-dragging still pans the view. Duplicate (Ctrl+D) creates the copy in place, selected: drag it or move it with the arrow keys. Overlapping lines (duplicates, copies not moved, shared edges, doubled DXF imports) are highlighted in pink so you spot them at a glance: the tool would pass twice over those portions. The Overlapping lines button in the Show group (or Settings › Display) turns this highlight on or off.

Drawing

The Drawing panel, as in Aspire: when you pick a tool or a function from the grid, its settings replace the icons. The blue cross at the top right, or a right click on empty space in the drawing, closes them and brings the grid back. When you click a vector, the grid stays and its settings (Selection, image…) appear below it; help texts open with the ⓘ icon.

Shapes and paths

  • Rectangle R, with square, external radius, internal radius (hollow arcs) or chamfered corners. Ellipse E (Shift: circle) and Circle from center C.
  • Typed values (circle, ellipse, rectangle, polygon and star, arc): the tool panel shows fields as in Aspire. Circle: center X/Y, radius or diameter. Ellipse and rectangle: reference point (9-point grid), X/Y, width and height. Polygon and star: center, radius, angle. Arc: start point, end point, radius and height (sagitta), linked together. Draw with the mouse: the vector stays selected and the values change it directly (corners and number of sides included); Confirm finishes it, and you can draw the next one. With no vector in progress, type the values then Create. To come back later to a vector drawn this way (even moved or resized), select it and click the pencil icon Edit dimensions in the Selection section.
  • Polygon and star O: number of sides or points, inner radius. Click the center then drag: the 2nd point snaps horizontally and vertically to the center (Ctrl: 15° steps).
  • Pen P (first tool of the Create row): click for a corner point, click-drag for a curve point, click the first point to close, double-click to finish. Near the horizontal or vertical of the previous point, the line aligns to it by itself (“Horizontal” / “Vertical” marker and dashes); with Ctrl, the angle moves in 15° steps (0°, 45°, 90°…). Extending a line: start the Pen on the end of an open line (“End” marker); the path continues that line instead of making a new one, and the curve to the next point leaves exactly along its axis (tangent). Drag from that first point, along the axis, to set the curve’s tension. The space bar ends the current line and starts a new one; a right click ends the line and leaves the pen. The Next point block in the panel creates points from the keyboard: type X and Y (absolute position), or an angle and a length L, or dx and dy from the last point. The six fields stay linked (typing the angle and length fills in X, Y, dx and dy) and a dashed preview shows the point. Enter or Add places it, Undo removes the last point, Close and Finish end the path.
  • Arc A: through 3 points (start, end, then the bulge) or, in Center, start, end mode, click the center, the start then the end: the arc goes the way you turn the mouse around the center.
  • Nodes N: move nodes and handles, double-click a segment to add a node, Alt while dragging a handle to break it, Shift to keep it horizontal or vertical to its node. Clicking a handle selects it (orange dot): its X/Y coordinates show in the panel, absolute or relative, and can be changed like a node’s. The L (handle length, its distance to the node) and Angle (0° to the right, 90° up) fields can be set too: changing L keeps the direction, changing the angle keeps the length. While dragging, nodes and handles snap to lines and to the extension of straight segments (dashed “Extension” marker): put a curve’s handle on the extension of the line before it and the curve is tangent to it. Four node types: Smooth (circle, aligned handles), Symmetric (dotted circle, aligned handles of the same length: dragging one mirrors the other), Cusp (diamond, two independent handles for a corner between two curves) and Sharp corner (square, no handles). Several nodes: Shift+click to add or remove one, drag a box in empty space to take them all at once (Shift to add), Ctrl+A for all. Selected nodes move together with the mouse or the arrow keys (1 mm, Shift 10 mm, Ctrl fine step depending on zoom, Alt ÷ 10). The X and Y fields give the node position in Absolute mode; in Relative mode, type an offset then Enter: it applies to all selected nodes. The buttons are sorted by use: node types (Cusp, Sharp corner, Smooth, Symmetric), segments (curve, straight), add, delete, cut, then Explode and Open / close; Smooth, Sharp corner and Delete apply to all of them. A selected segment (click it, it turns red) is deleted with Delete or the Del key: a closed outline becomes an open line, an open line is split in two. To switch to another vector, click its outline. Explode (also in the Modify row) cuts the profile at every node: each segment becomes a separate vector.

Editing

  • Chamfer K and Fillet F on one corner, or on every sharp corner from the Corners block. The corner can also be made by two separate vectors that touch (a line and an arc, for example): COPO joins them into one vector, then makes the fillet or chamfer.
  • Copy, cut, paste: Ctrl+C, Ctrl+X, Ctrl+V (also in the Edit menu). Each paste is offset by 10 mm and stays selected; groups and layers are kept. The clipboard also works from one project to another. With a relief selected, Ctrl+C then Ctrl+V pastes a copy.
  • Trim X deletes the part of a vector between two intersections; Cut U splits a vector where you click.
  • Extend vectors (Modify group): click the open line to extend, then move the mouse near one of its ends. Its extension shows as a dashed line, in the direction of the path, with a circle at each crossing with another vector. Click a crossing: the line is extended up to it. You can go on to the next crossing; Esc lets you pick another line.
  • Weld, Subtract, Intersect for boolean operations; Join and Close for open vectors, gaps being bridged by a straight line or by a smooth curve that continues both vectors; Offset contour: on a closed vector outside, inside or both sides; on an open vector to the right or left of the path, or all around (“Both” creates a closed outline). A negative distance goes to the other side (−1 with Outside = 1 mm inside). Sharp or rounded corners, and an option to delete the original.
  • Smooth (fit curves) (Modify): replaces vectors made of many small segments (tracing, DXF, import) with arcs, Bézier curves or straight lines that stay within the tolerance of the original. “Keep sharp corners” keeps as sharp corners those whose change of direction exceeds the max angle (60° by default). A dashed orange preview and the node count before/after are shown before applying; uncheck “Replace” to keep the originals. Arcs or Bézier? In COPO every curve (circles, arcs, ellipses, letters) is stored as Bézier curves, as in an SVG file. The Arcs mode finds the portions that follow a true circle (constant center and radius) and draws them with Béziers fitted to that arc, at most one per quarter circle: the gap from a perfect arc is about 0.03% of the radius (under a hundredth of a millimetre for a 30 mm radius). Use it for mechanical shapes (templates, fillets, holes): the radii are truly constant and give clean G2/G3 arcs. The Bézier curves mode gives free-form curves, often with fewer nodes on organic shapes (traced drawings, scrolls), but a “round” part is not necessarily an exact circle.
  • Align and distribute (vectors or reliefs; for reliefs, Shift + click in the 2D view picks several, and the same buttons are in the Relief tab): choose the reference in “Align to”. The selection: a single vector aligns to the stock, several align to each other. The first selected vector: it stays put and the others align to it; Distribute places them after it, in the order you selected them, with the given spacing. The stock: aligns to the stock edges and distributes across its full width or height.
  • Selection block: laid out as in vector drawing software: on the left the reference point (nine points), then X and Y, then W (width) and H (height), and the padlock that keeps proportions (blue: on). Below, the selection angle: type a value and the selection takes that angle by rotating around the pivot; then the Rotating frame box and the edit, duplicate and delete buttons.
  • Rotation (Arrange): an orange pivot appears at the center of the selection; drag it in the 2D view (it snaps to vectors, guides and the grid), pick one of the nine points, or type its coordinates. Relative rotation (the selection turns by the given angle, positive counterclockwise) or absolute (the selection takes the given angle; COPO remembers earlier rotations). ↺ 90° and ↻ 90° buttons for quarter turns.
  • Handles: click an already selected vector a second time. Squares resize (corners keep proportions when the “Keep proportions” padlock is on, Shift for the opposite, Ctrl for whole millimeters; middles resize one axis), circles rotate around the pivot (Ctrl: angle rounded to 15°, 0, 15, 30…; Ctrl + Shift: to the degree), and the pivot can be moved. Click again to hide them. The Rotating frame box (Selection block, unticked by default, under “Keep proportions”) makes the frame follow the angle of a rotated vector, so you stretch it along its own axes, as in Aspire (for a single vector, or vectors rotated by the same angle; a straight line takes its own direction, so its width is its length). The width and height of the Selection block are then those of the vector along its own axes, and changing them stretches it along those axes.
  • Moving with the keyboard: the arrow keys move the selection by 1 mm (Shift: 10 mm). With Ctrl, the step follows the zoom: about one screen pixel, rounded to 1, 2 or 5 (0.05 mm close up, 1 mm from afar), to place a vector precisely; Ctrl+Shift: ten times more. The step used is shown. Same for nodes and images.
  • Right-click and double-click: a single right-click in the 2D view finishes the current line (polyline), cancels a vector in progress, goes back to the selection tool and deselects; with the selection tool, it hides the handles and then deselects. Small icons (the letter P and its reflection) show the effect of each button. The Create a mirror copy box keeps the original in place.

Snapping, guides and dimensions

Edit › Settings › Snapping gathers the snap settings: snap to grid and its spacing, guides, stock corners, midpoints and center, snap radius (small to large), and vector snapping with its six kinds of points (ends and nodes, midpoints, intersections, centers, tangents, and on path: any point of a line or curve, the closest to the cursor). Precise points (end, midpoint…) take priority over “on path”. Center of a circle or arc: move the mouse near its outline and a small orange cross shows the center; go to it to snap there (also for circles made of straight segments, imported or vectorized). The origin (X0 Y0) is always a snap point. When you move a vector by grabbing one of its points (node, corner, midpoint, center), that point is the one that snaps: drag a rectangle’s corner onto the origin and it lands exactly there. These settings are remembered. Drag from a ruler to create a guide: drawn points snap to it, and when you move a selection its edges and center line up with the guides (and with the stock if that box is checked). Double-click a guide to open the Guides block (Measure group) on its position, to change it with the keyboard; the padlock on each row locks the guide, which no longer moves with the mouse. An orange symbol at the cursor shows the snap found. The grid icon below the 2D view shows or hides the grid. The Measure tool M gives a distance and the Dimension tool D places a dimension that stays in the 2D view. An end snapped to a node, a segment midpoint or the center of an arc or circle (solid dot at the end of the extension line) stays attached to the vector: move it, resize it or edit its nodes and the dimension follows, with its value updated. An end placed elsewhere (grid, intersection, free point) stays fixed.

Corners for tenons and mortises: dogbone and T-bone

A round tool leaves a fillet of its radius in corners, so a square tenon will not fit its mortise. The relief is drawn on the shape, corner by corner, so it only goes where it is needed. Take the Relief tool B (Modify group), choose Dogbone (the tool moves diagonally to touch the sharp corner) or T-bone (the relief extends the longer side, less visible) and the tool diameter, then click near the corners to relieve. The same settings are in the Corners block of the Drawing panel. Corners are picked one by one, as for chamfers and fillets. Relief only works between two straight segments; its diameter is 0.1 mm larger than the tool so it fits without forcing. Then machine the vector as usual (pocket, inside or outside profile) with that tool.

Project tab

The Project tab, first in the left panel, opens by itself when you create a new project. It contains:

  • Project type: Single-sided, Double-sided (the Double-sided block appears) or Rotary (4th axis). The settings below change with the choice. If the selected machine has no rotary axis declared, a warning appears under the Rotary choice, without blocking anything.
  • Rotary: the part is a cylinder turning between a chuck and a tailstock. Job size: length (L) and diameter (D). You draw on the unrolled surface of the cylinder, like a label laid flat: the sheet is L by π × D (the circumference, computed for you). The middle of the sheet is the top of the cylinder; dashed lines mark 90°, 180° and 270°, and the sheet edges are the seam (0° = 360°): a design crossing it must match up. Z zero: cylinder surface or axis. Orientation: rotation axis along X (Y wraps) or along Y (X wraps). The 3D view and the simulation show the part wrapped on the cylinder (uncheck to go back to flat, for example to place a relief with the handles). In the G-code, the wrapped coordinate is output as an A angle (or B, depending on the machine; degrees) with any post-processor, and arcs are replaced with short segments; a “Wrap” or “Rotary” post-processor (.pp) can also be used. Depths are measured towards the center: the deeper you cut, the more the design tightens.
  • Stock: X width, Y height, thickness and material (used by the setup sheet);
  • Origin: the X0 Y0 point on the nine-point grid, an X/Y offset to place it outside the stock, and Z zero on the top of the stock or on the table;
  • Double-sided: the flip axis and the sides shown;
  • Units: millimeters or inches, feed unit;
  • Machine (top of the tab): the name of the machine in use and its post-processor; Change… opens the machine library. On the left, the list of machines (the checked one is used for the G-code; click another to switch), with + New machine, Duplicate and Delete (two clicks to confirm). On the right, its settings, saved automatically: name, X/Y/Z travel (optional: the Project tab warns if the stock is larger), spindle speed range (tool speeds are clamped to it in the G-code), rotary axis fitted and its letter (A or B), notes. With the “GRBL manual” or custom post-processor, the Rise to a machine Z (G53) at tool changes box is off by default: a wrong machine Z can drive the spindle into its limit; when off, the spindle rises to the safe Z and G53 lines are removed, and: post-processor, rapid speed, maximum cutting feed (2000 mm/min by default: tool feeds are capped at this value), safe and clearance Z, G2/G3 arcs and comments. The G81/G82/G83 drilling cycles box writes holes as canned cycles: G81 plain, G82 with a dwell at the bottom, G83 with pecking, G98 retract to clearance Z. G83 has no dwell: a hole with both pecking and dwell is written as G0/G1. It is checked by default for grblHAL, LinuxCNC, Mach3/4, UCCNC and MASSO, and unticked for GRBL, Carbide Motion, Onefinity and the custom post-processor (holes are then written as G0/G1); you can always change it. If the controller does not know these cycles, it simply stops with an error.

The origin point must match the point where you set X0 Y0 on the machine. Stock, origin and material are saved with the project. Units and machine settings are remembered in the browser.

Example: with the origin at the bottom left corner, a square whose corner sits at X0 Y0 in the 2D view is cut from the bottom left corner of your sheet. The line under the grid tells you where the G-code X0 Y0 falls.

Machine library

In the Project tab, Machine › Change… opens the library. Each machine keeps its post-processor, speeds, safe heights, X/Y/Z travel, spindle range and rotary axis (letter A or B). The default machine uses the GRBL (M0 pause at tool change) post-processor, and rising to a machine Z (G53) at tool changes is off by default. The tool change can also be set in the machine: As set by the post-processor (default), No command (the tool only appears in a comment), Pause command (M0 or another command, at each change) or Tool change command (start command, tool number, end command: “T6 M6”, “M6 T6”…), with an example under the fields. Tool library

The library opens from the Tool library card in the Tools block of the Toolpaths tab (it shows the project material), from Machining › Tool library…, and from the Tool button of a toolpath window. Inspired by Aspire's, it comes filled: metric (mm) and imperial (inch) tools, sorted into end mills, ball nose, V-bits (including 30° bits for fine engraving and the carbide carving bits Ø 10 and Ø 32 with a 6 mm shank), engraving bits (flat tip) (carbide, 15° to 90°, 0.1 or 0.2 mm flat, 1 or 2 flutes), tapered ball nose bits and drills, named as in the catalogs, with settings for eight materials: softwood, hardwood, MDF, acrylic, PVC, HDPE, aluminium and brass. The first four come from an Aspire library tuned for a WorkBee-type machine; settings missing there are estimated for a hobby CNC from the CncFraises charts (“hobby”, very cautious) and the Sorotec charts (small diameters): feed per tooth by material and diameter, spindle speed from the cutting speed (between 8,000 and 18,000 rpm, feed capped at 2,000 mm/min), pass depth k × Ø (0.5 to 1 × Ø in soft materials, 0.1 to 0.35 × Ø in aluminium and brass), reduced because the tool often cuts its full width. PVC takes the acrylic settings. Estimated values are flagged by an orange banner: do a test cut and correct them. Below the settings, a tip recalls the rules of the material (chips, not dust; lubricate aluminium; plastics that melt…) and of the tool; a banner warns when the tool is not recommended for the material (two-flute javelot or carving bit in aluminium).

Your changes are saved in the library: they are used by every toolpath and every project that uses this tool with this material (a bubble says so at the first change). A You changed these settings banner flags them, with a Restore the original values button that brings back the settings shipped with COPO, or the estimate, for this material. The comment under the feed per tooth turns orange when the feed per tooth leaves the reference range or when the pass depth exceeds k × Ø.

  • Material (top): this is the project material, also set in the Project tab (Tool material). Changing it makes every project tool take that material's settings and recomputes the toolpaths. The + button adds a material.
  • Tree (left): click a folder to open it, double-click to rename it; the search box filters by name; “used” marks the tools of the project's toolpaths. At the bottom: new tool, new folder, duplicate, delete and back to the default library (two clicks). The Import… and Export… buttons are at the top right.
  • Settings (right): geometry (name, type, diameter, angle, engraving tip, number of flutes, T number, notes), then cutting settings for the chosen material. The name updates itself as long as you have not edited it.

Relief (modelling)

The Relief tab prepares sculpted machining, like Aspire’s modelling: each relief item is a height map placed in the stock. The tab opens the 3D view next to the drawing (2D / 3D buttons); the creation buttons show how to use them on hover.

  • Grayscale: insert the image (PNG, JPG) in the Drawing tab (Import › Image), place and size it, select it, then click Grayscale: the image is turned into a relief at the same place, size and angle, and leaves the 2D view. The relief is shown shaded in the 2D view and handled like a vector. Light is high, dark is low (check Invert for the opposite). A transparent background counts as black for heights but is not machined: with no boundary selected, machining stays within the opaque part of the image. For an image on a black background (a JPG, for instance), check Black background → transparent, no relief (threshold): anything darker than the threshold (8 % by default) becomes transparent, with no relief and no machining, and the rest of the relief starts from zero at the edge, with no step.
  • 3D model (binary or text STL): the model is seen from above and projected into heights, at its real size: it is never scaled down, even if it is larger than the stock. In that case, a message and the panel summary (in red) say so: enlarge the stock in the Project tab, or shrink the model yourself. If the model comes in lying down or upside down, X angle and Y angle tilt it (180° on X to flip it, ±90° to stand it up), Z angle turns it flat (other reliefs only have the Z angle). Undercuts are machined as seen from above. Also from File › Import an STL (relief)….
  • Settings of each item: position and size as for a vector (one of nine reference points, X, Y, width, height), relief height, stock top → relief top and stock bottom → relief bottom (editing one recalculates the other: their sum plus the height is the stock thickness), angle, softening and how it combines with the items before it: add, subtract, keep highest or keep lowest, or blend: where reliefs overlap, their heights are averaged, faded towards the item’s edges, without adding or subtracting. “Keep proportions” makes the height follow size changes. To delete an item, click the bin on its row in the list. When a relief is selected, its settings take the place of the creation buttons; the blue cross, or a right click on empty space in the drawing, closes them.
  • Limit with vectors: click Limit with vectors…, pick one or more closed vectors in the 2D view and click Apply the limit. The relief only exists inside those vectors (a vector inside another makes a hole); outside there is no relief. The limit follows the vectors if you edit them; Remove the limit gives the whole frame back to the relief.
  • Create outline: with a relief selected, this button creates a closed vector that follows its outline seen from above (STL, image, dome, sweep…), taking its rotation and limit into account. Then apply an outside Profile toolpath to cut the part out, or offset it with Offset.
  • Cutting out a relief without drawing its outline: in a Profile toolpath, click the relief itself, in the 2D view or in the 3D view. Its outline shows as a dashed blue line and the button becomes Compute around the relief. The depth is set automatically to the bottom of the relief (stock top → relief top + relief thickness, never more than the stock thickness); you can change it. The toolpath follows the relief's outline and is recomputed when you move or change it (update it). Click the relief again to remove it; you can also add vectors to the same toolpath.
  • In the 2D view, a relief (STL, grayscale, dome, extrusion or sweep) is handled like a vector with the Select tool: a first click selects it and opens its position settings in the Relief tab, and you can drag it to move it; a second click shows the handles: squares to resize (corners: proportions kept, Shift to distort; sides: one dimension only), circles to rotate (Ctrl: 15° steps); Ctrl resizes in whole millimeters. Delete removes it. Right-clicking a relief, in the 2D view or in the 3D view, opens its menu (toolpaths, outline, duplicate, delete…).
  • Display: in 2D, all reliefs (STL, grayscale, domes, extrusions and sweeps) are shown shaded under the drawing; the whole relief is visible in the 3D view. The summary gives the depth of the lowest point and warns if it exceeds the stock thickness. A relief that extends beyond the stock (after shrinking the stock, for example) stays fully shown, in 2D and 3D, but only the part inside the stock will be machined.

Relief data is kept in the browser and saved in the .copo file: each relief’s heights, images, and the full mesh of STL models. A project sent to someone therefore opens as is on another computer, without the original STL file, and the model’s orientation can still be changed.

Shapes built from the drawing

Select vectors in the 2D view, then click one of the three buttons under Create from the drawing. The shape is copied into the relief: editing the drawing afterwards does not change it.

  • Dome (one or more closed vectors; inner vectors make holes): height rises from the edge. Edge width = 0 domes up to the center (a ridge along elongated shapes, as in Aspire); a value gives a rounded edge of that width, then a plateau.
  • Extrusion (one or more vectors, open or closed): a molding of the chosen width follows the path, with rounded ends.
  • Sweep (two rails + one profile vector, all open): the drawn section spans from one rail to the other, scaled to the gap between them. The profile is the vector joining the two rails, otherwise the last one selected (changeable with Profile vector); its chord runs from rail to rail and its real height gives the Z height; Flip the profile reverses it if needed. Without a third vector, the section is round; Height at the end varies the height from start to end (scroll, neck, domed edge) and Height proportional to the width adapts it to the gap between the rails.
  • Sweep with several profiles: to make the section change along the rails, draw several profiles across, each from one rail to the other, where it should apply (both ends on the rails). Select both rails and all the profiles, then Sweep: COPO recognises the rails (the vectors the profiles touch), places each profile where it crosses the rails and blends the section gradually from one to the next, shape and height included. Before the first profile and after the last, the section stays that of the nearest profile. The Smooth transition between profiles box (checked by default) rounds the change from one section to the next: no kink at a profile, and the shape arrives flat at the first and last ones; uncheck it for a straight-line transition. The panel shows the number of profiles and their position as a % of the rails’ length. To move a profile, move its vector in the 2D view and create the sweep again.
  • Profile of domes and extrusions: round, angular (pointed), flat or ogee (S-shaped). Z height, base offset, combine mode and softening work as for other items.

Machining the relief

In the Toolpaths tab, the Relief type offers two operations, each shown by a small cross-section: roughing as steps around the relief, finishing following the surface. The strategies have their picture too: Z levels (flat steps) and 3D raster for roughing, Raster (back and forth) and Offset (passes following the outline) for finishing. Below the list of reliefs to machine, the Advanced options section (open by default) gathers the machining limit, with a picture showing the chosen limit in blue (model outline, stock outline or selected vectors), the offset, the tool position, the strategy and the steps.

  • Roughing: raster by Z levels with a flat end mill (the largest is suggested), each level stepping down by the pass depth, leaving an allowance (0.5 mm by default) for finishing. Default stepover: 40% of the diameter. Tool entry: Back-and-forth ramp by default (the tool goes down following the start of the pass, over the ramp length computed as for a profile, then returns to its start at full depth), Helix (the tool bores a 1.5 × Ø hole, going down by the chosen step-down per turn, at the first place along the pass where the circle fits entirely within the machining boundary and the material to remove, then joins the start of the pass; otherwise it ramps in) or Straight plunge.
  • Finishing: parallel raster following the surface with the real tool shape, never gouging the relief. Use a ball nose, a tapered ball nose (defined by D, R and L) or, for fine details, a flat-tip engraving bit (angle and tip diameter). A round-tip engraving bit is described as a tapered ball nose, using the box dimensions: shank diameter D, tip radius R, cutting length L; COPO derives the angle (D 6, R 1, L 20: 5.99°). Default stepover: 10% of the diameter; adjustable raster angle and an optional second cross pass at 90°.
  • Reliefs to machine: check the items whose outline limits machining (all by default). Heights stay those of the full relief.
  • Machining boundary: Model boundary (the checked reliefs, without the transparent background of images), Stock boundary (the whole stock) or Selected vectors (closed vectors selected in the 2D view). Tool relative to boundary: tool edge inside (default, the tool does not cross the vector) or tool center on boundary (the tool overhangs by one radius) or tool edge outside (the tool goes all the way around the relief and fully past it: the usual choice to finish a relief edge cleanly, with no offset to add). Boundary offset enlarges (positive) or shrinks (negative) the boundary, for example to leave room for a clearance.
  • Strategy: for roughing, Z levels (machines only below each level, in runs) or 3D raster (each line follows the surface without going below the level, fewer retracts); for finishing, Raster (parallel lines at the chosen angle, optional cross pass) or Offset (contours parallel to the boundary edge, from outside in, climb or conventional).

Passes are chained in zigzags region by region and short links stay on the surface, to limit retracts and air moves. If the relief changes after calculation, the toolpath says so in orange: open it and click Update. Finishing files are long (tens of thousands of lines), as in any carving software; the 3D preview replays roughing then finishing.

Toolpaths

At the top of the tab, the four buttons Profile, Pocket, V-carve and Drilling create a toolpath: select the vectors in the 2D view (even with the settings open), then click the operation. Its settings replace the buttons and the list in the panel, hiding nothing of the 2D view or the 3D view; the line Type: Profile · change lets you switch operation. Clicking a toolpath in the list opens its settings to edit it. The blue cross at the top right, or a right click on empty space in the drawing, closes them and brings the list back.

While the toolpath settings are open, the rest of the drawing and the other toolpaths are dimmed: only the selected vectors and the current toolpath stand out. Everything returns to normal when they close. At the bottom of the settings, a status line says what will be machined, for example “3 vectors selected (2 closed, 1 open)”; it turns red when nothing is selected, and warns when a pocket, V-carving or drilling will ignore open vectors.

The four types

  • Profile: Outside / right (the part is kept), Inside / left (the hole is cleared) or On the line. On an open line, Outside runs the tool to the right of the path and Inside to the left, in its drawing direction (Drawing › Reverse direction to change it); “On the line” follows the stroke or runs left or right according to the “Open lines” setting. On an open line offset to the right or left, ramp, tangent arc and ramped arc entries apply too: the arc enters and leaves on the waste side.
  • Pocket: four strategies, on one row of icons: Spiral in → out (starts in the middle and widens to the edge), Spiral out → in (follows the edge first, then tightens), Zigzag (parallel lines at the chosen angle, never a pass around the edge: edges slightly scalloped; the allowance does not apply) and Zigzag + contour (the same lines, then one pass around the edge to clean it). With a spiral, if a strip too wide for a single pass is left in the middle (depending on the pocket width and stepover), a clean-up pass is added automatically. Rest machining (Advanced options) uses the toolpath’s tool, the small one, for the corners a larger one could not reach. In After the toolpath, choose the pocket made before on the same vectors, for example “Pocket 1 (End mill 6 mm)”: its tool, depth and allowance are used. Or choose Create a toolpath…: COPO opens the library for the larger tool and creates a linked roughing toolpath before the rest machining, as in Aspire. With an allowance, the larger tool leaves it; the small one finishes the walls, except with “Do not remove the allowance”, where both leave it.
  • V-carving: the V-bit follows the medial axis of the path; it goes deeper where the stroke is wide and rises up to the tip of every corner. Branches are chained in the shortest order; between two branches the tool moves straight while staying inside the carving (at a safe depth, or just above the surface) and only rises to the clearance Z when the move would leave the design. Links are drawn dashed like moves, and the V-bit does not run along the bottom where the rings or the clearance tool have already removed the material. On later levels it rapids down to 0.2 mm above what is already carved, then plunges. With a clearance tool, each level first cleans the corners, then cuts the contour (the wall); the pass depth is kept everywhere. A maximum depth gives a flat bottom. With an engraving bit (flat tip) or a tapered ball nose, the depth follows the real tip shape: corners are rounded to the tip radius, areas narrower than the tip are not machined (in red in the 2D view, with a warning), and the tip clears flat bottoms itself when there is no clearance tool. A fine pointed V-bit (under about 60°) does not clear a flat bottom: add a clearance tool. The pass depth (the tool’s when left empty) splits the carving into steps, as in Aspire: deep areas are cut in several goes, with the same final result. The calculation precision (0.1 mm by default) is the spacing of the points used to compute the medial axis: 0.05 mm for small lettering. Clearance tools (flat end mills), chosen after the V-bit with + Add a tool…, can clear the flat areas: COPO sorts them from largest to smallest and adds, just before the V-carve, one linked “clearance” toolpath per tool; each one only removes what the previous one could not, and the V-bit only cleans up the edge. These toolpaths are set up from the V-carve. If you delete the V-carve, COPO asks whether to keep them as independent toolpaths. Renaming the V-carve does not touch its clearance toolpaths.
  • Drilling: one hole at the center of each closed vector, with optional pecking and dwell at the bottom (0 = none). Pecking is filled in automatically from the tool, set in the tool library according to the material: aluminium, copper, brass (long chips) 0.5 × D; steels, cast iron and plastics 1 × D; wood and MDF 2 × D. With a flat end mill, circles larger than the tool can be milled helically to the drawn diameter (box unticked by default); the option is hidden for a drill tool, a ball nose or a V-bit. When it is unticked, an orange warning points out circles larger than the tool, which will be drilled at the tool diameter (handy when you draw large circles just to see and select the holes more easily). With a drill tool, each hole is drilled at the tool diameter; COPO shows the tip length to add for a through hole.
  • Threading: tapped holes and screws milled with a thread mill (single-form, 60°), centered on each selected circle. Set internal (tapped hole) or external (screw), pitch, nominal diameter (0 = the circle’s: draw an 8 mm circle for M8), thread hand and number of radial passes; the thread length is the cut depth. COPO shows the pre-drill diameter (nominal Ø − pitch, e.g. Ø6.75 for M8 × 1.25). The tool always climb-mills, one helix turn per pitch, with tangent half-circle lead-in and lead-out; the feed entered is the cutting-edge feed and COPO corrects it at the tool center. For a screw, clear the material around the cylinder first. Two thread mills (Ø4 and Ø8 mm) were added to the library with estimated settings.

Toolpath recomputation: when the drawing changes, COPO only recomputes the toolpaths concerned (those whose vectors or settings changed); undo and redo reuse calculations already made. A long calculation runs in the background, with a progress bar: you can keep drawing meanwhile (if the drawing changes in the meantime, the toolpath is recomputed afterwards).

  • Automatic (default, Settings › General): a toolpath that is slow to compute (over half a second) waits for a pause of about 1.5 s without changes; you can make edit after edit without waiting, and the toolpath shows the ⟳ badge meanwhile. Opening the G-code tab recomputes it at once. If recomputing is often slow, COPO offers once to switch to manual.
  • Manual: affected toolpaths are marked ⟳ and keep their old path until you click Recompute toolpaths (below the toolpath list).
  • In both modes, an orange dot on the Toolpaths and G-code tabs flags out-of-date toolpaths; the banner in the G-code tab has a Recompute now button. G-code export, the setup sheet and the simulation first recompute what is out of date (in manual mode, COPO asks: Recompute and continue). The Recompute all toolpaths button stays available.

Advanced options: below the cut direction, this folding section (closed by default, COPO remembers your choice) gathers the allowance and its removal, projection onto the relief, the tool entry and ramp length, rest machining (pocket), and for drilling the helix, pecking and dwell. The allowance is 0 by default.

Passes, allowance and cut direction

Start depth (D) and Cut depth (C), as in Aspire: machining starts at depth D below the surface (for example at the bottom of a pocket already cut) and goes down by C from there, so the bottom is at D + C. For a profile or a pocket, C can be 0: a single pass at depth D (surfacing, or the tool resting on the relief with projection). Leave D at 0 to start from the surface. In V-carving, the pattern is computed as if the surface were at D, which is what inlays use. The small diagram next to the fields shows what D and C are. A negative value starts above the surface: the first passes cut air, useful when the stock is thicker than planned or its surface uneven (D = −2 and C = 5: start 2 mm above, bottom 3 mm deep).

Project onto the relief (profile, pocket, V-carving): the toolpath follows the surface of all visible reliefs of the Relief tab instead of the flat stock top (no need to select the relief: only select the toolpath’s vectors); depths D and C are then measured from the relief. The contact height takes the tool shape into account (V, ball nose, flat), to carve a pattern or lettering on a domed surface. Outside the relief, the toolpath stays measured from the stock top. Side 1 only; if the relief changes, the list flags that the toolpath must be recalculated.

The cut depth is split into passes of the chosen depth. An allowance leaves a little material on the walls while roughing; it is removed on the last pass or by a full-depth finishing pass, or left in place (Do not remove the allowance) to remove it with another finishing toolpath, for example with another tool. The cut direction is climb or conventional.

The ⓘ bubble next to Tool entry sums up the guidelines: helix diameter 1.5 to 2 × Ø in wood (1.2 to 1.8 × Ø in metal), ramp angle 5 to 15° in softwood and MDF, 3 to 8° in hardwood, 3 to 5° in plywood and aluminium, 1 to 3° in steel; ramp feed at 50 to 70% of the cutting feed. Ramp length = depth ÷ tan(angle): 5 mm at 10° gives about 28 mm. Under 1.2 × Ø, the helix almost plunges; beyond 2 × Ø, a bit that does not cut at the center leaves a post. The maker's values come first, and a bit that does not cut at the center must never plunge straight down.

Ramps and helixes go down at 60% of the cutting feed. In the 2D and 3D views, these descents are drawn in orange over the toolpath, to show where the tool enters the material.

Lutherie: fretboard and inlay

Guitar fretboard

Extensions › Guitar fretboard… draws the fretboard, nut on the left, centered on the stock. Set the scale length, the number of frets, the width at the nut and the second width, at the 12th fret or at the end of the scale, the overhang after the last fret, the frets with a marker and a double marker (lists of numbers) and the marker diameter. The scale line (checked by default) draws the center line from the nut to the bridge, with a mark at each end, to place the bridge. With the Zero fret box, a fret 0 is drawn at the start of the scale (with the same edge distance as the others) and the board starts before it, at the distance set in Board start → zero fret; the “nut” width is then the zero-fret width. The fret-to-edge distance stops the fret lines short of the board edge (0 = through frets). The preview updates live. The window opens next to the left panel, like the toolpath settings, and moves by its title.

Fret positions

COPO uses the exact equal-temperament formula, the one used by reference fret calculators:

dn = L − L / 2n/12  i.e.  dn = L × (1 − 2−n/12)

where L is the scale length, n the fret number and dn the distance from the nut to the fret. Each fret shortens the string by a semitone, a factor of 21/12 ≈ 1.05946; the 12th fret falls exactly at half the scale. The “rule of 17.817” gives the same result; the old, less accurate rule of 18 is not used. No compensation is applied to the frets: intonation is set at the bridge, moved back a few millimeters from the scale line.

V-carve inlay

Select the design (closed vectors), then Drawing › V-carve inlay…. The settings open in the left panel, with a dimensioned diagram as in Aspire: a pocket depth, g glue gap at the bottom, b male height below the backing (it must exceed a − g: the rest is planed off), c backing overhang, and an optional prefix for the toolpath names, built as layer_function_tool: female_clearance_6mm, female_vcarve_90deg, male_clearance_6mm… Choose the V-bit (Library… button for the whole library) and, if you like, flat clearance tools that first clear the flat areas (faster on large designs). As in Aspire, you can add several (+ Add a tool…): COPO sorts them from largest to smallest; the largest clears the flat areas, each next one is a rest machining toolpath linked to the previous one and only removes what it could not. The overhang c is automatic when left empty; the Create the toolpaths box can be unticked to draw only the male piece. COPO creates:

  • a female V-carving of the design in your part;
  • the male plug: the mirrored design inside a frame, on the “male” layer (the frame is not grouped with the design: it is the boundary of the male clearance, resizing it changes that toolpath; the mirrored design is a reference, the toolpaths use the working shape), with a V-carving that starts at the pocket depth minus the gap and goes down by the surface gap. All layers (“male”, “clearance”, “inlay (computed)”) and all toolpaths are created visible: to cut a single part, hide the other part's toolpaths (eye icon in the list) before saving the G-code.
  • with a clearance tool, a “clearance” pocket before each V-carving, where the V would reach its full depth. With an engraving bit (flat tip) or a tapered ball nose, the female and the male are machined on the same working shape, whose points and inner corners are rounded to the tip radius: the two parts fit down to the bottom (your drawing is not changed). The V-bit does not go over the bottoms already cleared: it cuts the wall, then only what the clearance tool could not reach because of its diameter (points, narrow passages). For the male, the clearance empties everything up to the frame (straight wall), at the depth where the V-bit works, and the V-bit only cuts the sloped wall of the design, in levels, plus the corners the clearance tool cannot reach: it touches neither the frame nor the flat bottoms. The automatic overhang widens so that the bit's cone stays inside the frame.

Flip the plug, glue it into the female pocket, then plane or sand off the excess. The V-carving Start depth setting is also available by hand in the toolpath form.

Pocket inlay (flat end mill)

Select the design (closed vectors), then Extensions › Pocket inlay… or, with a right click, Inlay › Pocket. The settings open in the left panel. Choose the flat end mill (the Library… button gives access to the whole tool library), the glue gap (0.1 mm by default) and how to make the male piece (Male piece on a backing board box). A small dimensioned diagram, as in Aspire, shows the values to fill in: a pocket depth, b male height (below the backing, or piece thickness without backing) and c backing overhang (automatic when left empty). The Create the toolpaths box (checked by default) can be unticked to create only the outlines. For large pockets, check Rough with a bigger tool: COPO recommends roughing or not depending on the pocket width and the main tool, and suggests a tool (from the project, otherwise from the library). The big tool then clears the pocket and the plug background, and the main tool only cleans the corners and narrow passages (rest machining): on a 60 × 40 mm pocket, the time drops by almost three.

A flat end mill cannot cut a corner sharper than its radius. COPO therefore computes a common outline whose corners, inside and outside, are all rounded to at least the tool radius: the pocket and the insert are machined exactly on this outline and fit without touch-up. The preview shows this outline in blue, the original drawing in dashed red, and the share of area changed; a warning flags parts thinner than the tool, which disappear.

  • Male piece on a backing board (box checked, default): the design is machined mirrored, raised, in a thick board, to a height b greater than the pocket a: once glued, the board stays b − a above the part, leaving room for the saw cut. Glue the board upside down into the pocket, then saw or plane off the excess. All parts of the design stay joined and go in at once.
  • Male piece without backing (box unticked): the design is cut out of a thin board of thickness b, with holding tabs. The cut-out depth is b when left empty; use a little more (b + 0.2 mm, say) to cut cleanly through if your spoilboard allows it. Make b equal to a for a flush piece, a little more if you want to sand after gluing; COPO warns when b is smaller than a. Break the tabs, sand, then glue the piece into the pocket.

Deleting an inlay toolpath also deletes the outlines it created (your original drawing is kept). COPO creates the pocket on the “Pocket inlay · female” layer and the insert to the right of the design, on the “Pocket inlay · male” layer. Both toolpaths are visible and go into the G-code; hide one (eye) if you machine the pieces separately.

Finger-joint box

The Extensions › Finger-joint box… menu opens this module, which draws a box assembled with straight finger joints, like Vectric's “Box Creator”. Set the outer dimensions (width X, depth Y, height Z), the material thickness (the stock's by default), the finger width (their number, always odd, follows), the joint allowance (0.1 to 0.2 mm in wood), the cutting tool, the top joint (finger-jointed for a closed box, the default, or laid flat for a removable lid) and the faces to machine (Top, Bottom, Sides, Ends). Fingers are spread evenly between the corners: the corner zone, as thick as the material, only exists where another panel joins, so an open box keeps the same pitch up to the top. Fingers may be narrower than the thickness; COPO warns when the slots become narrower than the tool. The Dogbone reliefs option adds an arc the size of the tool at the bottom of each slot so square fingers fit.

The preview shows the panels laid flat. Create the box places them on the stock, spaced for the tool: cut them with an outside profile and tabs. The panel volumes fit exactly: no overlap or gap at the corners.

Rotary graduations

In a rotary project, Extensions › Rotary graduations… draws evenly spaced lines around the cylinder: graduations, verniers, flutes, gear teeth. The lines are always parallel to the cylinder axis chosen in the Project tab (horizontal when the cylinder lies along X, vertical along Y) and spread around the circumference (π × D).

  • Number of divisions and span: at 360°, as many lines as divisions all the way round. Below 360°, the divisions cover the span with a line at each end; for a tenth vernier, for example, 10 divisions over 9°.
  • First line angle: 0° is the origin line, like the 0°, 90°, 270° marks in the 2D view.
  • Position and length: as in the Selection block, choose the line's reference point (start, middle or end), then its X (or Y) position relative to the origin and its length.
  • Longer lines: a medium line every n lines and a long line every m lines, each with its own length; they start from the same reference point. First line number shifts this count.

The preview shows the unrolled sheet and the pitch, in degrees and in millimeters on the surface. Create the lines places them as a group on the active layer; machine them with V-carving or an “on the line” profile.

Nesting

Drawing › Nesting… opens the block in the Drawing tab. Select the parts (with no selection, the whole drawing is used) and set the number of copies, the spacing, the sheet margin, the allowed rotations and the precision. COPO places the parts following their true shape, largest first, as far down and left as possible. A group or a text stays in one block. Parts that do not fit stay selected, and the sheet usage is shown.

For cut-outs, use a spacing at least equal to the tool diameter. Ctrl+Z undoes the nesting if you don't like the result.

Double-sided machining

  1. Put the vectors of the bottom side on a layer set to F2 (F1/F2 button in the layer list). Draw them as seen from above, see-through.
  2. Choose the flip: around the X axis (top ↔ bottom) or the Y axis (left ↔ right).
  3. Side 2 toolpaths are calculated on the flipped geometry; the cut direction is kept.
  4. In the G-code, side 1 is followed by an M0 pause: turn the part over, set X0 Y0 Z0 again at the same point and resume.

The 3D preview shows both sides; the Side 2 up option shows the part flipped.

2D and 3D views

The 2D and 3D buttons at the top work as two switches: 2D only (the drawing fills the area), 3D only (the relief), or both at once. When both are shown, the buttons next to them place the views side by side or one above the other, and the divider between them can be dragged to enlarge either one (double-click: half and half). The Relief tab shows the 3D view automatically.

The 3D view shows the relief in the stock (wireframe), with the drawing and the axes. The view uses an orthographic projection (no perspective), handy from the front or the side. Hold the right button: orbit (around the point under the cursor, unlimited, you can go under the part); hold the middle button: pan; wheel: zoom towards the cursor; double-click: whole stock; a left click selects. As in Fusion, FreeCAD or Tinkercad; the mouse is set in Settings › 3D views. Top right: the view cube. At the bottom, icon bars like in the 2D view: on the left, show or hide the drawing, the axes, the stock and the toolpaths (cuts in their type’s color, rapid moves in gray); in the middle, the transform tools; on the right, fit all on the relief. Transforming a relief in 3D. Click an item in the 3D view to select it (its box corners are highlighted; the selection is shared with the 2D view and the list). The bottom bar offers three tools, with dimensions shown at the top left:

  • Move: drag the X, Y or Z arrows (Ctrl: whole millimeters). In Z, the relief top snaps to the stock top and its bottom to the stock bottom; in X and Y, its edges snap to the stock edges.
  • Rotate: drag the blue ring (around Z); for an STL, the red and green rings also tilt it around X and Y (Ctrl: 15° steps, Ctrl + Shift: 1° steps).
  • Resize: drag a corner to scale keeping proportions (Shift, or “Keep proportions” unticked: freely), a side to change only the width or the length, or the blue dot above for the height: the top moves, the bottom stays put. Ctrl moves in whole millimeters.
  • The last two buttons drop the relief onto the stock bottom or align its top with the stock top.

Each transformation can be undone with Ctrl+Z; the relief panel keeps the exact values.

3D preview

Detail: the simulation only computes the area actually machined (the rest of the stock is drawn solid); the smaller the area, the finer the result. The Resolution setting (Standard, High or Very high: 0.5, 1.5 or 3.5 million points) raises the detail further; the resolution used is shown at the bottom of the window. A long simulation is computed in the background: the window opens at once on the stock (Computing the simulation… at the bottom) and playback becomes available when the calculation ends.

The preview simulates material removal through the real stock thickness, through-holes included. The playback buttons replay the machining: back to start, step back, play / pause, step forward and go to end; one step is one tool move. Keyboard: left and right arrows, Home, End and Space. Relief and finished part: the Relief box overlays the designed relief (a line mesh at its real height) to compare it with the machined material. The post-processor, rapid speed (for the time estimate), safe Z, clearance Z, comments and G2/G3 arcs are set in the Project tab, Machine block. The file gets the extension the post-processor expects (.nc, .tap, .ngc).

Curves and G2/G3 arcs. COPO does not send Bézier curves to the machine as they are: toolpaths are computed as short segments, then, when “G2/G3 arcs” is checked, circular portions are recognised and written as true G2/G3 arcs (shorter file, smoother motion). A circle drawn with the Circle tool or a vector smoothed in Arcs mode gives exact arcs; a free-form curve is approximated by a series of arcs and lines, within tolerance.

Always check the G-code with a dry run, tool above the stock, before cutting.

Units: millimeters or inches

In the Project tab, Units block, choose the Length units (millimeters or inches) and the Feed units (mm/min, mm/s or in/min). The choice applies everywhere: drawing, rulers, grid (1/16, 1/8, 1/4 and 1 inch), coordinates, dimensions, tools, toolpaths and setup sheet. In inches, one option shows values as fractions (to 1/64) and another writes the G-code in inches (G20) for controllers set up that way.

The project is always saved in millimeters: you can switch units at any time without distorting anything, and a project opens correctly for someone working in the other unit. The choice is remembered in the browser.

Setup sheet

The Setup sheet… button in the G-code tab (also in the Machining menu) prepares a two-page setup sheet for the workshop. Enter the part name, the material and your notes; the sheet contains:

  • the stock, X0 Y0 origin, Z zero, flip and post-processor;
  • a summary: estimated time, maximum depth, machined extent from the origin, cutting length and removed material volume;
  • the 2D view of each side with toolpaths, origin and stock dimensions, and two dimetric views of the simulation (side 1 and side 2);
  • the tool loading order, then the toolpath table: operation, tool, depth, passes, allowance, entry, tabs, feed, plunge and time;
  • the points to watch it detects (cut through the stock, cut-out without tabs, pass too deep, job outside the stock, hidden toolpaths);
  • a checklist before starting, a notes area and sign-off boxes.

Save as PDF (in the sheet window, or straight from File › Save the setup sheet as PDF without opening it) creates an A4 PDF file, split into pages without cutting tables or pictures, ready to print or send. The PDF is a picture of the sheet (text not selectable); for a PDF with text, use Print then the browser's “Save as PDF”. You can also keep the HTML file with the G-code. The sheet settings are saved with the project.

Install and use offline

  • Online: open the GitHub Pages site of the COPO repository. Nothing to install.
  • As an app (Chrome, Edge, Brave, Vivaldi… on Windows, macOS and Linux): Help › Install COPO as an app… or the install icon in the address bar. If the icon does not appear, use the browser menu: in Chrome, ⋮ › Cast, save and share › Install page as app…; in Edge, … › Apps › Install this site as an app. If COPO is already installed, the browser offers “Open in COPO” instead. COPO then opens in its own window with its icon in the app menu, works offline once loaded, and double-clicking a .copo file opens it directly (the file icon depends on the system). Updates arrive automatically when online. Firefox and Safari do not offer this install: COPO works normally there in a tab.
  • Offline: download the complete COPO folder (“Code › Download ZIP” on GitHub) and unzip it. Open index.html with a double-click: everything is already in the lib folder (calculation libraries and interface fonts) and in the fonts folder. Nothing else to install or download.
  • Interface fonts: the lib/fonts folder holds the COPO fonts (Source Sans 3, JetBrains Mono, Barlow Condensed). Offline, the interface, the setup sheet and this guide keep the same look.
  • Engraving fonts: put your .ttf, .otf or .woff files in a fonts folder and open it once with the Open a fonts folder… button of the Text block.

COPO runs on Windows, macOS and Linux, in a recent Chrome, Edge or Firefox. The list of installed fonts is only available in Chrome and Edge.

Report a bug

Help › Report a bug… menu: describe the problem, then click Open the report on GitHub. The report arrives pre-filled with technical information (browser, units, stock, toolpaths, recent errors). The 2D view screenshot is copied to the clipboard: paste it into the report with Ctrl+V. If you check “Attach the project”, drag the downloaded file into the report. A free GitHub account is enough. Ideas for improvements are welcome too at github.com/gbulleryahen-hash/copo/issues.

Help › Suggest an improvement… opens the same window for an idea: describe the feature you want and what it would be used for; it reaches GitHub with the enhancement label. Both carry the COPO version number (also shown in Help › About): 1.n, where n goes up with every published update.
